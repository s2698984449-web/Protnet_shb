### 两套评分，不要混用

**元训练（本次日志）**

- 查询分类准确率。5-way 随机水平 0.20；铸坯留出的测试是 3-way（crack / oxide / scratch），随机水平 0.333。
- 早停监控验证 loss：`early_start=100`，`patience=10`。
- `loc@0.2`：有标注的查询上，预测峰与真值峰的归一化坐标 L1 距离 < 0.2 的比例。只出现在验证行，测试收尾行不打印。

**工业交付（现行成熟架构，另一套协议）**

冻结 ImageNet ResNet18 layer4，不训练投影。目标产线每类 3～5 张建原型：

`score = (1-cos(core)) + 0.25·(1-cos(ring))`

主指标是缺陷准确率、Δbg、Δhard（缺陷准确率 − max(贴块背景, 几何)）。图像自助区间 2.5%～97.5%。分母 CR7 / GC10 / NEU。过线：β 在 k=3/5 无排序反转；三来源 Δbg 为正；Δhard 区间下界 > 0。跨来源支持只作附录。这套分数不是上面的 episode 准确率。

仓库里没有 ProtoNet、Matching、Relation 的同协议实测，不另填公开论文数字。

## 收敛前结论摘要（产物已删）

| 主题 | 结论 |
|---|---|
| 同来源元训练 | 测试准确率约 0.867；定位弱 |
| 见过来源换源 | 约 0.80；非未见产线 |
| 铸坯留出 | 约 0.43～0.48；对齐权重无救 |
| 源域投影 C | 相对冻结原型无稳定 Δbg 增益；不进 E |
| L2/L3、DINO | 非三来源同向过门禁 |
| 切块+cosine | 同源抬 Δbg；跨源部分有效 |
| patch 对照 | 相对 `core_cos` 三来源全负；未开对齐训练 |
| v3 门禁 | 对称画布 + 贴块背景；主指标缺陷−背景 |
