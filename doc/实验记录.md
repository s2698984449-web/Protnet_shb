### 2026-11-20 B0 正式训练 `b0-v1`

- 目的：在冻结 Meta-Train 上训练二分类缺陷定位器，用固定 Meta-Val Episode 选模
- 配置：`config/baseline.yaml`；12 epoch，batch size 1，学习率 0.0025，`grad_clip_norm=10`，每数据集每轮 512 个物理组、正负各半、每组 1 视角；评价用产品宏平均 AP50
- 命令：`conda run -n MAML --no-capture-output python -u scripts/train_b0.py --run-name b0-v1`
- 产物：`output/baseline/runs/b0-v1/{best.pt,last.pt,metrics.json}`，说明见 `doc/b0_training.md`
- 结果：12 轮跑完；最佳第 6 轮，产品宏平均 AP50 ≈ 0.00014；其余轮次大多接近 0
- 结论：训练流程与边界校验打通，但检测效果几乎无效，不能作为可用基线

### 2026-11-20 锚框短跑对照 `anchor-ab-local`

- 目的：在相同小样本预算下比较默认锚框与小锚框，定位 RPN 召回问题
- 配置：`config/b0_short.yaml`；每数据集 1 个产品族，训练 16 组 / 留出 12 组，4 epoch；`default=[32,64,128,256,512]`，`small=[8,16,32,64,128]`
- 命令：`conda run -n MAML --no-capture-output python -u scripts/run_b0_short_queue.py --queue-name anchor-ab-local --workers 4`
- 产物：
  - `output/baseline/short_runs/anchor-ab-local-default/metrics.json`
  - `output/baseline/short_runs/anchor-ab-local-small/metrics.json`
  - `output/baseline/short_runs/queues/anchor-ab-local/comparison.json`
- 结果：default 留出 AP50 ≈ 0.0019，RPN Recall@50 ≈ 0.032；small 留出 AP50 / RPN Recall@50 均为 0
- 结论：缩小锚框没有改善；当前瓶颈更像候选框排序或前景打分，而不是单纯锚框尺度偏大

### 2026-11-20 RPN 候选预算对照

- 目的：检验扩大 RPN 候选预算能否提高最终检测效果
- 配置：同一 `b0-v1/best.pt`，18 条冻结 Meta-Val Episode，837 张唯一 Query 图，置信度工作点 0.5
- 命令：`python -u scripts/sweep_b0_rpn_budget.py --checkpoint output/baseline/runs/b0-v1/best.pt --output output/baseline/short_runs/anchor-ab-local-default/rpn-budget-local.json`
- 产物：`output/baseline/short_runs/anchor-ab-local-default/rpn-budget-local.json`
- 结果：Top-50、Top-100、Top-300 的产品宏平均 AP50 分别为 0.0001414、0.0000757 和 0.0000217。平均前向耗时分别为 39.8、47.4 和 80.3 ms。Top-300 的正常图误报升至产品宏平均 1.29 框/图，工作点召回仍为 0
- 结论：后续诊断以 Top-50 为对照，并用真值框直接检查 RoI 分类与回归

### 2026-11-20 B0 RoI 真值框诊断

- 目的：绕过 RPN 候选选择，区分 RoI 分类和框回归的问题
- 配置：`b0-v1/best.pt` 第 6 轮权重，冻结 Meta-Val 的 6 个产品各取 6 张缺陷图和 6 张正常图，72 张图来自不同物理组。正常图用 Top-50 RPN 候选。真值框水平平移框宽的 20%，用于检验扰动框的缺陷类别回归
- 命令：`python -u scripts/diagnose_b0_roi.py --checkpoint output/baseline/runs/b0-v1/best.pt --output output/baseline/short_runs/anchor-ab-local-default/roi-b0-v1-best.json`
- 产物：`output/baseline/short_runs/anchor-ab-local-default/roi-b0-v1-best.json`
- 分类：85 个真值框前景分数中位数为 0.00146，1,800 个正常图候选框为 0.00109。按这两组框分数计算的总体诊断 AUROC 为 0.589，Real-IAD 子集为 0.263。85 个真值框的最高分为 0.211，全部低于 0.5
- 回归：真值框回归后的 IoU 中位数为 0.969，全部保留 IoU ≥ 0.5。85 个扰动框的 IoU 中位数由 0.667 降到 0.660，23 个改善。10 个原本命中真值的 Top-300 候选框中，9 个回归后仍然命中，且全部低于 0.5 置信度
- 结论：RPN 候选不足之外，已确认 RoI 前景排序区分度弱。框回归对所测扰动未带来总体改善，但很少把原有匹配推到 IoU 0.5 以下。分类分数在框级抽样上计算，结果用于故障定位
