# 项目说明书

日期：2026-11-28。主线：**条件化五模块检索式 FOMAML**（v5→v5.2）。未见过的产品只用 Support；相似度只召回；ψ 按模块决策 `(z, c, ρ)`；硬门控；借的是块不是整套。检测目标是框出缺陷。训练损失推动参数，不代替 AP50。

环境 `MAML`，CUDA。入口：`python -B -u scripts/train.py`。

## 1. 现状（fold 0）

| 阶段 | 产物 |
| --- | --- |
| 划分 / Episode | 已冻结（`output/splits`、`output/episodes/v1`） |
| B0 / θ₀ | `b0-v3`；`theta0/fold_0/fold0-detloss-v1/last.pt` |
| 经验库 | `experience_bank/fold_0/fold0-bank-5module-v1`（θ₀ 冻结建库） |
| 条件化 FOMAML | `fold0-fomaml-conditional-v5/v51/v52-e10` |
| 留出 | 同名 `*-holdout`；三臂 **K0 / K1(Null) / Borrow** |

近期宏 Borrow−K1：v5 **+0.0067**（全借）、v5.1 **+0.0102**（全借）、v5.2@0.5 **0**（全拒）。扫阈值不能当主改进。Outer Test 封存。

## 2. 任务与五模块

二分类缺陷定位（背景 / 缺陷）。1-way 5-shot，K 按物理组。Support / R / Query 池两两不相交；Query 不参与选卡。

| 模块 | 典型前缀 |
| --- | --- |
| Backbone | `backbone.` |
| Where | `rpn.` |
| RoiFeature | `roi_heads.box_head.` |
| Box | `roi_heads.box_predictor.bbox_pred.` |
| Class | `roi_heads.box_predictor.cls_score.` |

动作 \(a_m=(z_m,c_m,\rho_m)\)：`z` 硬拒借，`c` 多卡 Softmax 混合，`ρ∈(0,\rho_{max}]` 强度。注入 \(\Delta\theta_m=z_m\cdot\rho_m\cdot\mathrm{step}\cdot\mathrm{mix}_m\)；多模块 **named 增量相加**（加性组合，非联合子集搜索）。

## 3. 数据与划分

见 `config/data.yaml`、`split.yaml`、`episode.yaml`。种子 `20261120`。Outer Test 11 族封存；Meta-Train 34；Meta-Val 8。第 0 折训练 27 族、留出（OOF）7 族：`capsule` / `zipper` / `eraser` / `mint` / `pcb` / `woodstick` / `chewinggum`（各 3 Episode，共 21）。

## 4. 检测器与损失

Faster R-CNN + ResNet-50 FPN；几何与 RPN 匹配见 `config/baseline.yaml` / `b0_v3`。FOMAML 用检测对齐损失（RoI / positive / ranking / hard_negative / localization）+ RPN，详见 `config/fomaml.yaml`。`last.pt` / `query_best.pt` 按 Query 损失；正式好坏看留出 AP50。

## 5. 训练流程（代码主链）

```text
prepare(audit/split/episodes)
  → b0 → theta0
  → experience-bank          # build_experience_bank：θ₀ 冻结，写卡片
  → fomaml --experience-bank # θ + ψ(+α)；每轮刷 experience_epoch_k
  → holdout                  # ψ/α 冻结；K0 / Null / Borrow
```

入口映射：`scripts/train.py` → `training/theta0.py`（fomaml）/ `experience_bank.py`（建库与一步）/ `meta_transfer.py`（holdout）/ `transfer_policy.py`（ψ）。

### 5.1 一个 epoch（`theta0._train`）

1. 用**当前 θ** `refresh_experience_cards` → `experience_epoch_{e}`，只留当前轮。  
2. 打乱 Meta-Train Episode。  
3. 每条调用 `retrieval_fomaml_step`。  
4. 记 `mean_query`；可选训后自动 holdout。

### 5.2 单步 `retrieval_fomaml_step`（核心）

| 步 | 做什么 | 代码 |
| --- | --- | --- |
| 签名 | Support 任务键 Appearance/Morphology/Difference | `task_signature` |
| 决策 | 图序 Backbone→Where→Roi→Box/Class；下游读上游 embed/ρ/z | `plan_modules_in_graph_order` → `plan_module_borrow` |
| 召回+ψ | Top-K 相似卡 → MLP → `card_logits, null_logit, ρ`；`mix=softmax(logits/T)`；`z_hard=1[p_null<thr]`（STE） | `hard_borrow_gate`；`mix_cards_from_logits` |
| 探索 | 对本步 LOO 目标以 `force_close_prob` 强制关，下游重规划 | `force_close_plan` |
| 内层 | 合并已 inject 的 `named`，注入后 Support 一步；Δ 相对「注入后」 | `retrieval_support_adapt` |
| 外层 θ | 借用臂 Query 损失反传共享 θ（一阶） | `query_total_packed_grads` + SGD |
| 反事实 | 同 RNG：**Null 臂**无借；整任务 \(U=L_\mathrm{null}-L_\mathrm{borrow}\) 只日志 | `counterfactual_adapt_query_loss` |
| LOO | 每步 1 模块：已借 \(U_m=L_{-m}-L_\mathrm{all}\)；未借 Add-One \(U_m=L_\mathrm{all}-L_{\mathrm{all}+m}\) | `module_leave_one_out_utilities` |
| 探针 | ρ 档配对 / 单卡配对（可 `probe_alternate`） | `module_rho_and_card_probes` |
| 更新 ψ | \(L_\mathrm{amp}=(-U_m)\,z\,\rho\,\mathrm{step}\,\|\mathrm{mix}\|\) +（v5.2）`null_sign` 边际；禁止整任务 U 广播 | `apply_counterfactual_policy` / `counterfactual_policy_loss` |

硬门控：`p_null=σ(null_logit)`，`z_hard=(p_null < null_eval_threshold)`，默认阈值 0.5。v5.2 另有 `null_sign_refuse_weight=2` 等，易把策略推进「常 Null」。

### 5.3 留出（`run_holdout`）

对每条 OOF Episode，同一种子、同一 Support：

1. **K0**：不适应，直接评 AP  
2. **K1 / Null**：无注入，Support 一步，评 Query  
3. **Borrow**：ψ 决策后注入，再 **同一套** Support 一步，评 Query  

主指标：产品宏 **Borrow−K1 AP50**；记每模块是否 inject、`p_null`、`ρ`。`--null-eval-threshold` 可覆盖，仅诊断。

## 6. 常用命令

```text
python -B -u scripts/train.py experience-bank --theta0 output/meta_transfer/theta0/fold_0/fold0-detloss-v1/last.pt --run-name fold0-bank-5module-v1

python -B -u scripts/train.py fomaml --theta0 output/meta_transfer/theta0/fold_0/fold0-detloss-v1/last.pt --experience-bank output/meta_transfer/experience_bank/fold_0/fold0-bank-5module-v1 --run-name fold0-fomaml-conditional-v52-e10 --epochs 10

python -B -u scripts/train.py holdout --supervised output/meta_transfer/theta0/fold_0/fold0-detloss-v1/last.pt --fomaml output/meta_transfer/theta0_fomaml/fold_0/fold0-fomaml-conditional-v52-e10/last.pt --run-name fold0-fomaml-conditional-v52-e10-holdout --device cuda
```

配置：`config/fomaml.yaml`（内外循环）、`config/retrieval_fomaml.yaml`（召回/ψ/LOO/探针）。续训 `--resume`；轮数可 `--epochs` 覆盖。`episode.yaml` 须保持 **LF**，否则冻结哈希失败。

## 7. 评价口径

| 考试 | 数据 | 含义 |
| --- | --- | --- |
| Meta-Val / `--val-ap50` | 8 族 | 选模；借用可关 |
| fold0 留出 | 7 族 21 条 | K0 / K1 / Borrow；主看 Borrow−K1 |

模块贡献按「旧产品某块 → 新产品」记账；缺 U 不补 0。不要求七族同时变好。有好借用 ≠ 全模块打包都有收益。

## 8. 已知痛点（定位用）

1. **v5/v5.1**：几乎 5/5 全借；宏正靠少数爆款（如 capsule），其余族常为负 → 缺选择性。  
2. **v5.2**：`null_sign` 过强 → 训练第二轮起近乎全 Null；抬阈值强制开，Borrow−K1 仍≈0 或为负 → **主要是没学好选择性/组合，不是单靠阈值**。  
3. **组合**：当前是加性 \(\sum_m\Delta\theta_m\) + 弱上游条件；**不是**「在某一特征前提下再开 Box/Class」的联合规划。单模块 LOO ≠ 子集联合效用。
