## 2. 任务

二分类缺陷定位。类别 `0` 背景，类别 `1` 缺陷。不输出划痕、裂纹这类细分名称，也不输出产品名。产品由任务给定。Mask 转框。正常图是空标注。一条 Episode 没抽中的缺陷进 Ignore，不当背景负样本。

一条任务是一个产品族，1-way 5-shot。K 按物理组计，组内视角一起移动。

| 角色 | 数量 | 用途 |
| --- | --- | --- |
| Support | 5 个缺陷组 | 挑选模块，内层更新 |
| R | 5 个纯正常组 | 只随 Episode 保存 |
| Query-Defect | 5 个缺陷组 | 外层损失和评价 |
| Query-Normal | 5 个纯正常组 | 外层损失和评价 |

查询图不参与挑选。混合正常和缺陷的 Real-IAD 组只能整组进入 Support 或 Query-Defect。

| 模块 | 参数前缀 | 挑选 |
| --- | --- | --- |
| Feature | `backbone.`、`roi_heads.box_head.` | 同一批候选上的检测损失，越低越好 |
| Where | `rpn.` | 候选覆盖，越高越好 |
| Box | `roi_heads.box_predictor.bbox_pred.` | 同一批候选上的检测损失 |
| Class | `roi_heads.box_predictor.cls_score.` | 同一批候选上的检测损失 |

收益不大于 0 则该块为 Null。收益为正时加上「权重 × 这一块」，权重上限 `reuse_weight_cap=0.5`。损失型权重是相对降幅；Where 的权重是覆盖提升量。

## 4. 检测器、激活、冻结

Faster R-CNN + ResNet-50 FPN。几何 `config/b0_v3.yaml`：短边 1024，长边 1536，只缩小，按 32 填充。RPN 相似度是 `max(IoU, NWD)`，NWD 常数 12.8。前景、背景赋值阈值沿用 TorchVision 默认 0.7 和 0.3。推理保留 RPN 后处理 50 个候选，每图最多 50 个框。

初始化：`config/b0_pretrained.yaml` 的 ImageNet ResNet-50。FPN、RPN、二分类头随机初始化。`trainable_backbone_layers=5`，五个卷积 stage 的卷积核都参与 B0 和 θ₀。

激活：

| 位置 | 激活 |
| --- | --- |
| ResNet-50 卷积块 | ReLU |
| FPN | ReLU |
| RPN 头卷积 | ReLU；随后的分类和框回归是线性层 |
| RoI `box_head` 的 fc6、fc7 | 两层之间 ReLU |
| `cls_score`、`bbox_pred` | 线性，无激活 |
| 推理缺陷分数 | 两类 softmax。工作点用类别 1 的概率 |
| 检测对齐损失里的缺陷分数 | `logit_1 - logit_0`。整体平移两个 logit 不改变这项分数 |
| 正例、高分负例、排序 | softplus |
| 定位 | GIoU |

冻结：

| 部分 | B0 与 θ₀ | 四模块 FOMAML 内层和外层 |
| --- | --- | --- |
| 骨干卷积、FPN | 更新 | 更新，归 Feature |
| 骨干 BatchNorm | `FrozenBatchNorm2d`。均值、方差和仿射都不更新 | 同样不更新。参数差不含这些缓冲区 |
| RPN | 更新 | 更新，归 Where |
| RoIAlign、框编码 | 无参数 | 无参数 |
| `box_head` | 更新 | 更新，归 Feature |
| `cls_score` | 更新 | 更新，归 Class |
| `bbox_pred` | 更新 | 更新，归 Box |

FOMAML 先把检测器全部 `requires_grad_(False)`，再只打开上表四块的参数。可训练参数 41,299,161。骨干和 RPN 都参加内层和外层。已完成的 `fold0-fomaml-tasks` 是旧设置，只更新了 `cls_score` 和 `bbox_pred`。

## 5. 损失

B0 和 θ₀ 用检测器自己的训练损失，批大小 1：

- RPN：objectness 的二元交叉熵，框回归 smooth L1
- RoI：二分类交叉熵，框回归 smooth L1

优化在 `config/baseline.yaml`：SGD 学习率 0.0025，动量 0.9，权重衰减 0.0001，梯度裁剪 10，12 个 epoch。每数据集每轮 512 个物理组，正负各半，每组 1 个视角。

FOMAML 一张图的训练损失是检测对齐损失加 RPN 损失。RPN 两项之和乘 `where_loss_weight=1`。检测对齐损失五项：

| 项 | 权重 | 内容 |
| --- | ---: | --- |
| roi | 0.25 | 采样 RoI 上的交叉熵与 smooth L1 |
| positive | 1 | 每个真值框的最佳候选，softplus(0 − 缺陷分数) |
| ranking | 1 | 正例分数至少高于高分负例 0.2 |
| hard_negative | 1 | IoU 低于 0.5 的候选里分数最高的 16 个，softplus(分数 − 0) |
| localization | 0.5 | 正例框的 GIoU |

正、负 IoU 阈值都是 0.5。梯度检查点打开。这条损失不是 AP50。`last.pt` 按一轮 Query 损失均值保存，早停耐心 1。损失下降不能当成检测变好。选模看 Meta-Val AP50，留出看留出 AP50。

FOMAML 外层 SGD：学习率 0.001，动量 0.9，权重衰减 0，梯度裁剪 10。内层一步，学习率 0.01。3 个 epoch。

## 6. 一条 FOMAML 任务

历史库按产品族只留最近一条四块参数差。库空时四块都是 Null。顺序：

1. 读 Support 和 Query。两者的图像和物理组不能重叠。RoI 监督不够则跳过，权重不动。
2. `--prescreen-k>0` 且库非空时，在当前 θ 上对 Support 做一次反向，四个模块各做一个 CountSketch。Feature 和 Where 按负梯度草图与历史差草图的余弦取前 k 个，去掉本族。Box、Class 仍看全部其他族。草图默认 4096 维、fp16、种子 20261124。
3. 精确评分只用 Support。选中的块按权重加到 θ 上。
4. 内层只用 Support，四块一步 SGD。记入记忆的是相对「加上借用之后」的参数差，不含借来的那一截。
5. 外层只用 Query 损失做一阶更新，更新的是共享 θ。然后把借来的增量减回去。

`MAML(first_order=True)` 只声明一阶。训练用原地 SGD，不克隆第二套检测器。留出评价才对 RoI 头调用 `clone()` 和 `adapt()`。参数镜像放在普通 CPU 张量上，同步拷贝。训练循环不调用 `empty_cache()`。内存里每个产品族只留最新一份参数差；更早的任务差写到 `module_memory_parts`，数值与原来的 float32 差相同。留出加载仍只用最后一轮里每个产品的最后一条。每完成一次外更新就覆盖写 `resume.pt`。中断后用同一命令加上 `--resume`，从下一条任务继续。已有断点时不能无 `--resume` 重开。

打开 `--val-ap50` 时，开训前和每轮结束在 18 条 Meta-Val 上、借用关闭、一步 Support 适配后算 AP50。只有严格高于 θ₀ 才替换 `val_best.pt`，否则标记 `theta0_best`。不读 Outer Test，不用 Query 标签调训练。`last.pt` 仍按损失保存。

结束后自动做一次只加载、不评价的留出演练。失败只打印原因，不删文件。早停或最佳损失轮不是最后一轮时，现有加载规则会拒绝这份权重。

## 7. 命令和开关

```text
python scripts/prepare.py audit
python scripts/prepare.py annotations
python scripts/prepare.py split
python scripts/prepare.py episodes
python -B -u scripts/train.py b0 --run-name b0-v3
python -B -u scripts/train.py theta0 --fold-id 0 --run-name fold0-detloss-v1
python -B -u scripts/train.py fomaml --theta0 output/meta_transfer/theta0/fold_0/fold0-detloss-v1/last.pt --run-name fold0-fomaml-modules --prescreen-k 4 --prescreen-audit 30 --val-ap50
python -B -u scripts/train.py holdout --supervised output/meta_transfer/theta0/fold_0/fold0-detloss-v1/last.pt --fomaml output/meta_transfer/theta0_fomaml/fold_0/fold0-fomaml-modules/last.pt --run-name fold0-fomaml-modules-holdout
```

轮数、学习率、损失、复用上限在 `config/fomaml.yaml`。下面的开关只在命令行，不改 yaml。

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| `--prescreen-k` | 0 | Feature、Where 精确评分前保留的源数。0 为四块全量，且不做预筛反向 |
| `--prescreen-audit` | 0 | 全量核对次数上限 |
| `--prescreen-audit-every` | 10 | 其他族超过 `2k` 后，每隔这么多条抽一条全量核对 |
| `--sketch-dim` | 4096 | 草图维度。与已存维度不同则用参数差重算 |
| `--val-ap50` | 关 | Meta-Val 上比较 θ₀ 和当前权重的 AP50，借用关闭 |
| `--val-max-episodes` | 0 | 0 表示 18 条全用 |
| `--pilot` | 关 | 1 个 epoch、1 条 MVTec Episode |
| `--dry-run` | 关 | 只校验边界 |
| `--resume` | 关 | 从 `resume.pt` 的下一条任务继续。开关、θ₀ 和任务必须与断点相同 |

`k=4` 时，其他族超过 8 个才开始抽查。已有 `last.pt` 或 `resume.pt` 的运行名不能直接重开。没有这两份文件时，同名可以重开。续训命令在原命令后加 `--resume`。

调用：`scripts/train.py` 的 `b0`、`theta0`、`fomaml`、`holdout` 分别进入 `training/train_b0.py`、`training/theta0.py`、`training/meta_transfer.py`。一条任务的损失在 `training/fomaml_roi.py` 的 `live_detection_loss`。

日志每条任务按阶段打印：标注、预筛、四块、内层、外层。每 10 步汇总 Query 损失和四块的 `产品族@权重`。`Null` 是没有正收益。`0.000` 表示权重大于 0、小于 0.0005。`FOMAML 进入` 行里的显存是任务开始时的驻留，不是反向峰值。

`fold0-detloss-v1`：27 族，12 轮，每轮 1,536 步，共 18,432 步，无跳过，142.2 分钟。总损失 0.1526 → 0.2480。RPN 两项 0.0666 → 0.0165，RoI 两项 0.0860 → 0.2315。每轮样本不同。检测能力看留出 AP50，不看这个损失。

2026-11-23 夜间那次在视角回退之前：每轮 40 条成功、41 条因单视角无 RoI 监督跳过，只覆盖 16/27 族。Query 均值 0.901 → 0.682 → 0.562。逐条记录已被后来的启动覆盖，不能当作现行代码的成绩。
