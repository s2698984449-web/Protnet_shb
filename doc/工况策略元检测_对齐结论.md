# 工况还原与策略引导的元检测：对齐结论

本文只记录已经对齐的结论、仍然存在的隐患，以及预期网络的初步框架。策略网络是主模块。PPO 只在出现不可微的多步复检时才作为可选训练算法，不进入第一版结构。

## 1. 已对齐的结论

任务是缺陷检测：输出已知缺陷的类别，并给出位置。热力图是空间分数图。类别和位置从同一张按类的空间距离图里读出：得分最高的类是类别，该类图上的峰值区域是位置。只有正常样本、没有缺陷类原型时，才退回单张异常热图。

现有元学习头在 `layer4` 做完 FiLM 后立刻全局池化，得到 128 维向量，输出 `(查询数, 类别数)` 的整图 logits，没有位置。转换方式是保留池化前的 `512×7×7`，每个位置投影到 128 维，再与支持集的各类原型计算距离，得到 `(类别数, 7, 7)`。整图类别由这张空间图池化得到，旧的图像级精度仍可对照。

扩散网络的输出是元学习检测的一部分输入，不是检测结果。它把难成像工况还原到参考工况，例如可检的光照和对比度。还原后的图像要重新过骨干提取特征。原图特征保留为另一路。扩散不把缺陷涂成正常表面。

策略网络告诉元学习这一次从哪路特征、哪个尺度入手，用来降低工况难度。元学习内部仍要提取特征、用支持集建原型、按位置做判断。检测头和元学习的适应能力必须本身够强。策略不代替检测头。

现有 NEU-CLS 上的元学习已经具备同分布缺陷类别的检测能力和 episodic 学习能力。这个能力是检测头的基础，不是跨光照能力的证明。

## 2. 数据和标签

### 2.1 本地已经有的

| 数据 | 标签 | 能支持什么 |
| --- | --- | --- |
| NEU-CLS | 6 类整图标签：Cr、In、Pa、PS、RS、Sc。无框、无掩码 | 现有图像级元学习。`domain_0/1/2` 分别是 train/val/test，不是不同光照 |
| GC10-DET | 缺陷类别 + XML 边界框 | 类别，以及框级位置。不能直接监督像素轮廓 |
| MVTec | 测试集有像素级异常掩码；缺陷类型按产品分开 | 热图和位置。类别空间与 NEU 的 6 类不是同一套 |

因此：类别训练，NEU-CLS 已经支持。位置的有监督训练，NEU-CLS 不支持。要做类别加位置，需要换带框或带掩码的数据，或增加 NEU-DET。

由整图标签反推的响应图可以画出来，但没有位置标签就无法计算定位误差，不能当作位置检测已经训成。

### 2.2 开源数据里能补上的

- NEU-DET：与 NEU-CLS 相同的 6 类，带边界框。这是和当前钢铁实验最直接的位置补充。没有配对光照。
- GC10-DET：本地已有，10 类钢板缺陷，边界框。
- Severstal 钢材缺陷：4 类，像素掩码。类别集合与 NEU 不同。
- MVTec AD：像素掩码，适合异常位置；各产品缺陷名不统一。
- MVTec AD 2：包含复杂光照，适合做工况测试。部分测试标签不公开，不能用来训练策略或调阈值。

没有现成的大规模开源集同时满足：同一条真实缺陷、两种真实光照、像素对齐、并且带类别和位置。光照还原的训练可以先用合成光照。缺陷是否被保留，不能只靠合成光照上的检测精度来证明。

## 3. 分阶段训练

扩散和元检测都有可训练参数，必须分阶段。两端一起从随机初始化训练时，扩散的重建梯度会压过检测梯度，缺陷容易被抹平。

1. **检测头。** 继续用现有 NEU-CLS 元学习，确认图像级类别检测稳定。这一阶段不接入扩散。
2. **空间读出。** 骨干从第 1 阶段初始化。在 NEU-DET、GC10-DET 或 MVTec 掩码上，把池化改为按位置与原型计算距离，学会类别和位置。
3. **工况调制。** 训练工况编码和 FiLM，损失仍是检测损失。缺工况标签时退回原特征。
4. **扩散还原。** 冻结检测头。扩散只学习把图像变到参考工况，并用已有框或掩码约束缺陷区域不要被改写。验收看缺陷还在，不看生成图好不好看。
5. **接成一条输入。** 冻结扩散，或只给很小的学习率。还原图和原图两路特征进入检测头。策略只学习两路的混合权重和尺度权重。检测头用自己的 episodic 损失更新。

PPO 不在这些阶段里。只有以后出现“放大局部再检、或停止”这种不可微动作，并且可微策略已经稳定，才单独比较。

## 4. 元学习学到的规则，和策略网络

元学习学到的是检测规则：支持集如何形成原型，查询特征如何与原型比较，以及少量参数如何在新支持集上适应。给定特征之后，这套规则负责判断。

策略网络学到的是检测入口：这一次用原图特征还是还原图特征，用哪个尺度，通道如何门控。它不输出类别，也不改距离公式的结果。

两者串联，不共用同一个输出头，就不冲突。职责重叠只出现在一种情况下：现有 FiLM 已经按工况改写特征，外层策略又去改同一路通道。处理办法是把 FiLM 留在编码器内部，属于检测特征的一部分；策略只在原图特征、还原图特征、尺度之间做选择。

检测头先在容易工况上成立。同一零件、光照正常时，空间原型距离就应给出类别和大致位置。这一步不成立，扩散和策略只是把图像送进一个弱头。

## 5. 仍然存在的隐患

- NEU-CLS 上的好结果是同分布 6 类图像级分类。`domain_0` 到 `domain_2` 是训练到测试，不是新光照、新零件。不能把这个结果写成跨工况检测已经解决。
- 位置标签和类别标签不在同一个协议里。NEU-CLS 无位置；NEU-DET 有框但无掩码；MVTec 有掩码但类别体系不同。混在一个精度里会把任务说不清。
- 现有标签是整图类别。无掩码时，空间峰值只是“这类原型在图上哪里最近”，定位误差无法严格评估。
- 零件编码若使用查询图，缺陷外观会进入条件，再影响原型匹配。零件表征只从支持集来。
- 没有配对光照时，工况向量和零件向量都从同一批图像估计，纹理会被写进工况码。工况编码必须能在元数据缺失时单独工作。
- 扩散的常见目标是把异常恢复成正常外观。本方案要求只改光照、留下缺陷。合成掩码上的保持损失，保住的是合成区域，不是真实细划痕在新光照下的形态。生成图更锐时，检测指标也会上升，这不能当成保真。
- 策略的状态若包含当前热图，而训练损失使用源域缺陷标签，策略会变成第二个检测头，记住源域缺陷长什么样。状态里只放不确定性、两路特征差、原型分散程度。
- 正常 Patch 记忆库本身不是新方法。要证明的是：跨任务训练出来的入口选择，在没见过的零件或光照上仍然有效。必须保留固定融合和随机门控作为对照。
- 图像级扩散在当前显存和数据上不是第一交付。特征级工况对齐先闭环。扩散接上之后，原图支路必须还能独立工作。

## 6. 预期网络的初步框架

```text
难工况图像
    │
    ├─ 原图 ──────────────► 共享骨干 ──► 原图 Patch 特征
    │
    └─ 扩散还原到参考工况 ─► 同一骨干 ──► 还原图 Patch 特征
                │
                ▼
        策略网络（混合权重、尺度权重、通道门控）
                │
                ▼
        混合后的空间特征  ×  支持集各类原型
                │
                ▼
        (类别数, H, W) 距离图
            ├─ 类别 = 得分最高的类
            └─ 位置 = 该类图上的峰值区域
```

模块约定如下。

| 模块 | 作用 | 谁更新它 |
| --- | --- | --- |
| 共享骨干 | 从原图和还原图提取 layer2、layer3 或未池化的 layer4 | 检测阶段更新；扩散阶段冻结 |
| 扩散 | 把光照等成像因素变到参考工况，输出仍是图像 | 单独阶段更新；接入后冻结或极小学习率 |
| 工况编码与 FiLM | 在编码器内部调制特征；无工况时保持原特征 | 检测损失 |
| 支持集原型 | 按缺陷类别聚合空间特征，元测试时用 K 张支持图重算 | 不单独存成固定分类器 |
| 策略网络 | 两层 MLP，输出原图/还原图混合系数和尺度权重 | 检测损失对门控的梯度 |
| 检测头 | 每个位置到各类原型的距离 | episodic 分类与定位损失 |

内循环若保留，只更新投影层和门控等小参数，不更新扩散，也不更新整个骨干。推理时策略只做前向选择，不使用缺陷标签，也不更新参数。
