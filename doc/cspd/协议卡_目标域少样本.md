# 协议卡 · 目标域少样本（基线）

与 [阶段性基线.md](阶段性基线.md) 对齐。范围是多产线钢板的少样本导入，不是通用缺陷检测。

## 定稿

1. **特征**：冻结 ImageNet ResNet18 layer4；不训练投影/适配器。
2. **区域**：`core`=mask 内；`ring`=膨胀 16px 减 core；远背景只作贴块基线对照。
3. **分数**：`d_core + β·d_ring`，`d=1-cos`；**β=0.25**（铸坯开发集锁定）。
4. **支持**：目标域每类 k∈{3,5}；与查询按伪批次（图像统计聚类）分离。
5. **主指标**：Δbg、Δhard（缺陷准确率 − max(贴块背景, 几何)）；附报混淆。
6. **分母**：CR7、GC10、NEU（NEU 框占比≤0.5，丢 pit）。CAST 仅开发选参。
7. **区间**：图像自助 2.5%～97.5%；≥20 组支持集。
8. **跨来源支持**：附录；不作交付卖点。

## 覆盖（训练划分，铸坯不在表内）

8 类 × 6 来源共 4402 张。很多类只在一两个来源出现，留一之后的「跨域」常常是成对迁移。

只用来源编号、猜该来源张数最多的一类：1527/4402 = 0.347（CR7、NEU、PLATE 有并列，并列两类张数相同，准确率不变）。全局最多类 inclusion 是 957/4402 = 0.217。类别与来源的互信息 0.940 bit（H(Y)=2.868，H(Y|来源)=1.927）。来源编号带着类别信息；铸坯是新来源，这条线索在测试时不存在。

core/ring 要求掩码。XSDD 三个划分掩码都是 0，不进这条路径。去掉 XSDD 后，留出一个有掩码的来源，还能跨来源测的类如下（括号是其余有掩码来源里仍有该类的个数）：

| 留出来源 | 可测的类 |
|---|---|
| CR7 | inclusion(3)、oil(1)、pit(2)、punch(1)、scratch(2) |
| GC10 | crease(1)、inclusion(3)、oil(1)、pit(2)、punch(1) |
| NEU | inclusion(3)、oxide(1)、pit(2)、scratch(2) |

NEU 留出时 crack 没有第二个有掩码的来源，不可测。括号为 1 的类是成对迁移。oxide 若算上 XSDD 的 471 张，训练来源是 3 个；core/ring 丢掉 XSDD 后只剩 NEU 和 PLATE。β 实验和主训练栈因此不是同一份数据，两边的数不要互相引用。

查询图的 core/ring 用的是这张查询图自己的掩码，在划分支持/查询之前就算好。不用距离图峰值。`loc@0.2` 只属于训练时的空间头，不进入工业分数。

## 通过（已满足于 industrial_proto）

- β 在 k=3/5 无排序反转  
- 分母三来源 Δbg 正向  
- 至少两来源 Δhard 区间下界 > 0（实测三来源均过）  
- NEU 跨 0 则标风险、不再调距离（实测未跨）
