# 思路历程（阶段性收敛）

## 2026-11-11 · layer3 留出混淆表明短板已从空核转到同源近邻

主题：layer3 权重上，留出短板还是不是空核，错分是不是仍是原先那几对近邻。

结论：准确率与官方留出一致，短板机制已经换了。NEU 800 张查询只错 39 次，夹杂 → 麻面从全开时的 47 次降到 9 次，这一折不再是卡点。CR7 仍是同一组近邻：局部坑 → 夹杂 44，油污 → 夹杂 24，线状 → 局部坑 23，夹杂与局部坑对打；油污在 layer3 上空核已是 0/8，召回 0.43 是进了夹杂和局部坑。GC10 油污仍进夹杂 16、水渍 14，召回仍是 0.41，同样不是空核；新的第一错是冲孔 → 焊缝 24，对应冲孔召回掉到 0.51。局部坑在 14×14 上仍有 2/8 空核，但 CR7 的主导错分是坑、油污、线状和夹杂挤在一起，不是格子不够。

依据：`scripts/probe_holdout_confusion.py` 在 `layer3_p1` 的 `last.pt` 上按官方留出协议重测，结果在 `D:/cspd_probe_holdout/`；与训练日志的 `test holdout` 数字一致。

后续：下一步仍用关闭组设定、layer3、种子 0、100 步。不要换 layer2，不要抬 ρ，不要加新损失，也不要用留出测试的混淆来抽题。现有 `hard_pairs` 只在进度 ≥0.75 的同来源 episode 里插入一对，而且这对来自验证集的跨来源混淆；ρ=0 时这个钩子几乎不起作用，也对准不了油污、局部坑、夹杂这类同源近邻。应改成：困难对只来自训练来源的验证集同来源混淆，从训练前段就提高这些对的抽题频率。留出仍只作最终对照。成功标准是三折留出不低于现在的 0.951 / 0.706 / 0.665，并抬高 CR7 油污、线状、局部坑和 GC10 油污、冲孔的召回，且不把 NEU 拉回去。中心化仍不作第一杠杆。

## 2026-11-11 · 关闭组设定下改到 layer3，三折留出明显超过关闭组和 ringfix

主题：core/ring 改到 14×14 池化、空核改用膨胀区之后，关闭组三折留出有没有超出种子波动。

结论：有，而且幅度很大。NEU 0.951、CR7 0.706、GC10 0.665，对关闭 seed0 的 0.799、0.534、0.618，差值是 +0.152、+0.172、+0.047，都超出关闭组三个种子的极差。相对 ringfix 也是同向。增益集中在原短板：NEU 夹杂 0.50→0.86、麻面 0.70→0.93；CR7 压痕 0.57→0.88、夹杂 0.46→0.78、油污 0.26→0.43、局部坑 0.35→0.53、线状 0.38→0.48；GC10 丝斑 0.47→0.70、焊缝 0.77→0.94。根因要修正：不只是空核。NEU 六个类在 7×7 上本来就没有空核，却从 0.802 跳到 0.951，说明即便核非空，7×7 对核心也太粗。GC10 油污完全没动（0.41），冲孔还从 0.61 降到 0.51，这两处不能用占用解释。

依据：当时 `output/cspd/layer3_p1/{NEU,CR7,GC10}/train.log` 的 `test holdout`；占用探针的 layer3 图像空间膨胀统计。权重抄完后已删。

后续：把 layer3 关闭组当作新的对照，不再把 7×7 空核当成主卡点。下一步先看留出混淆，而不是再加 ρ。

## 2026-11-11 · 修正 ring 后留出仍与关闭组打平，短板机制是空核

主题：把 `_core_ring` 改成输入分辨率 16 像素膨胀之后，关闭组设定下的三折留出有没有动。

结论：没有超出种子波动。NEU 0.802、CR7 0.540、GC10 0.613，对关闭 seed0 的 0.799、0.534、0.618，差值是 +0.003、+0.006、−0.005，都落在关闭组三个种子的极差里。实现错误是实在的：旧代码在 7×7 上用半径 16 膨胀，有核时环等于补集；核对脚本已证明新环与图像空间膨胀一致。但主指标不跟着动。CR7 油污仍是 0.26，局部坑 0.35、线状 0.38，只比 v3 略高。分数是 `d_core + 0.25·d_ring`，核心项权重是 1；layer4 空核时核心退回整图均值，环再正确也抬不动主导项。卡点仍是来源内部近邻，尤其是裁切到 224 后在 7×7 上经常空核的小缺陷。

依据：`output/cspd/ringfix_p1/{NEU,CR7,GC10}/train.log` 的 `test holdout`；占用探针与 `scripts/verify_core_ring.py`。

后续：下一步只改空核，仍用关闭组设定、种子 0、100 步，先把 core/ring 改到 layer3（14×14）池化，或 layer4 空核时回退 layer3。不要再抬 ρ，不要加到 200 步，不要把这次写成跨来源课程有效。中心化仍不作第一杠杆。layer3 上 CR7 局部坑仍有 2/8 空核，若短板还在，再改空核回退，不要继续用整图均值顶替核心。

## 2026-11-11 · 课程膨胀在 7×7 上是补集，小缺陷常空核

主题：裁切到 224 之后，mask 在 layer4 / layer3 上占几格，以及 16 像素膨胀实际圈到哪里。

结论：两件机制问题同时成立。其一，课程 `_core_ring` 把 `dilate_px=16` 作用在 7×7 上，核比特征图大；NEU 六个类 8/8 膨胀铺满，环就是核心的补集，不是工业路径里输入分辨率 16 像素的邻域。图像空间膨胀后环大约 5～12 格，几乎不铺满。其二，CR7 油污、局部坑、线状在 layer4 上空核分别是 4/8、5/8、7/8，空核时膨胀也是空的，核心和环都会退回全局均值。改成图像空间膨胀不减少空核次数。layer3（14×14）上油污空核降到 0/8，线状 1/8，局部坑仍有 2/8。这是实现与协议不一致，不是新方法。先改 ring，空核留到 ring 修正后短板仍在再处理。

依据：144 张 train 图、18 个（类，来源）各 8 张、种子 0 的占用统计；`DualRegionBetaDetector._core_ring` 与 `encode_core_context`。

后续：先把 ring 改成与工业路径一致并重跑关闭组对照。不要先抬 ρ，不要加到 200 步。

## 2026-11-11 · v3 相对关闭组基本打平，未证明冲孔跨来源有增益

主题：ρ=0.20、只冲孔跨来源、β 固定、100 步，三个种子 0 留出是否符合预期。

结论：符合「先别再伤留出」的预期，不符合「冲孔跨来源带来明显增益」的预期。NEU 0.815 略高于关闭 seed0 的 0.799，明显高于全开 0.781；CR7 0.515 对关闭 0.534，GC10 0.623 对 0.618，都在单种子噪声里。CR7 / GC10 全程抽不到冲孔跨来源，只能当同预算复核。真正掺了跨来源的 NEU 也只比关闭高 0.016，弱类仍在（夹杂 0.57、麻面 0.67；CR7 油污 / 坑 / 线状仍低）。200 步是全开配置，不是 v3；v3 故意用 100 步对齐关闭组。下一步不要加长到 200 去复现全开；若继续，应先量 layer3 占用或中心化，而不是再抬 ρ。

依据：`output/cspd/v3/{NEU,CR7,GC10}/train.log` 的 `test holdout`；训练 `got>0` 为 58/100、0/100、0/100。

后续：把 v3 记为「恢复到关闭附近」；不据此宣称跨来源课程有效。中心化或层占用探针再开。

## 2026-11-11 · 留出学的是比较方法，不是对齐同名类

主题：冲孔跨来源抽不到时，留出实验还测什么。

结论：留出测试的类含义由新产线自己的支持图给出，不由训练时的同名文件夹给出。投影在其他产线的同产线 episode 里学会把裁切后的缺陷嵌到能分开的空间。部署时新产线每类给几张图，用这几张做原型，再认这家的查询。同名但长得不一样的类不应当跨来源正样本，否则是在把不同缺陷压进同一个原型。冲孔是目前唯一看图认为是同一种缺陷的一对，所以只有它适合做少量跨来源。留出 CR7 或 GC10 时这一对凑不齐，v3 会退回同产线训练，和 v1 接近，主要是重复。能看出 ρ=0.20 加冲孔跨来源有没有改变留出的，是留出 NEU 这一次。

依据：`curriculum_v3.yaml` 的 `cross_classes: [punch]`；冲孔只在 GC10 与 CR7；v1 留出 NEU 0.810、CR7 0.539、GC10 0.614。

后续：三次都可以跑。解读时把 NEU 当作新设定，把 CR7、GC10 当作和 v1 同预算的复核，不把三次都当成冲孔跨来源已生效。

## 2026-11-11 · 先把训练改回同产线比较

主题：留出变差之后，第一处修改放在哪。

结论：主因是训练任务和留出任务不一致。留出是同一条新产线上的支持和查询；全开后段大多是两条已见产线之间的同名匹配。投影只有 1×1 的 65664 个参数，学到的是这些来源之间的对齐。环区膨胀核是 `2×16+1=33`，作用在 7×7 特征图上，核比特征图大，环等于整幅特征图减去核心，不是核心旁边一圈。下一步确认跑只改采样：ρ 平台不超过 0.20，跨来源 episode 只用冲孔，β 固定 0.25。中心化留到这一跑的留出仍低于关闭组再加。layer3 要先量裁切到 224 之后 core 占几格，不用原图框宽代替。

依据：九次全开对九次关闭；`DualRegionBetaDetector._core_ring`。

后续：成功标准仍是留出追上 0.810 / 0.539 / 0.614，并且弱类错分下降。损失不加新项，早停保持关闭。

## 2026-11-11 · 同名类已经是交叉熵里的正样本

主题：跨来源正样本是不是只有冲孔；困难类加采样会不会改损失。

结论：查询交叉熵里，文件夹同名就会被当成正样本。划痕、夹杂、氧化皮、油污、折痕在 ρ>0 时已经这样训练。冲孔是其中唯一看图认为本体相同的一对，所以只有它适合再加拉近，或在跨来源正表里单独报。其余同名类继续可以出现在 episode 里，但不另加对齐损失。困难类对只改变抽题频率，单次损失仍是查询交叉熵；抽得越多，这类题在总梯度里越重。自适应加采样只应用于同一来源内部、验证集上已经缠住的类对，不用留出测试的混淆，也不把三种坑互当正样本。

依据：`CurriculumNewSplitEpisodes` 按语义文件夹组跨来源 episode；`class_manifest.yaml` 中 exact 只有冲孔；留出混淆见实验记录。

后续：损失公式不改。若改采样，先降 ρ 平台，再提高同一来源内的困难对频率。

## 2026-11-11 · 不把旧凹坑并类的 0.15 当成当前根因

主题：跨域失败是否仍该按「凹坑原型没对齐」来改损失和采样。

结论：NEU 麻面同源高、跨源约 0.15，是旧目录把麻面、局部坑、轧坑收成同一个凹坑之后的数。这三类现在已经拆开，兼容表定成不兼容，不再做「NEU 坑查询、CR7 坑支持」的跨来源 episode，也不加只对 exact 类的拉近损失——exact 只有冲孔。当前留出上的错分是同一家内部的近邻：CR7 局部坑、油污、线状进夹杂，GC10 油污进水渍，NEU 夹杂进麻面。全开比关闭差，是 ρ 升到 0.80 并且 β 贴上沿，不是坑还没拆开。损失和采样先不加大跨域项。若改，只把 ρ 平台降到不超过 0.55，β 范围收窄；困难类对继续只用训练来源的验证，而且应是留出上真正缠在一起的那几对，不是把三种坑再拉近。

依据：实验记录里的旧凹坑矩阵和 2026-11-11 留出混淆；`class_manifest.yaml` 中麻面、局部坑、轧坑为 incompatible。

后续：不跑「统一 pit 对拆分 pit」的消融，拆分已经是现行目录。不按见过来源的同源/跨源调和平均来早停。

## 2026-11-11 · 落差来自后段损失，不来自清单没写完

主题：待做第一节第一行和全开落差是不是一件事；训练损失算不算符合预期。

结论：三层兼容矩阵只有初稿，等级仍暂定，第二人没看。留出协议不靠这张矩阵，所以九次留出的高低不是矩阵没锁造成的计算错误。矩阵管的是同名文件夹能不能当成同一类。全开后段 ρ=0.80，训练真的把同名类拉到一起；清单里这些对大多只是 related，exact 暂定只有冲孔。训练损失按这个目标下降了：NEU 从 0.93 到 0.37，CR7 从 1.14 到 0.29，GC10 从 0.94 到 0.27，训练准确率升到 0.89–0.95。验证的同来源 loss 没有跟着降。日志只写了各类召回，混淆矩阵算过但没有落盘，现有召回说明不了油污错成哪一类。解释落差不必先补矩阵；要解释 CR7、GC10 为什么停在 0.5 附近，需要在 `STEEL_p1m_*` 的 `last.pt` 上把混淆写出来。关闭组权重已删，那一侧补不了。

依据：`doc/cspd/待做.md` 第一节第一行；`output/STEEL_p1m_{NEU,CR7,GC10}/train.log` 的 iter 1 与 iter 200；`evaluate_curriculum` 把 `confusion` 只交给困难类采样。

后续：不把「损失下降」写成留出变好。混淆只补弱类错到谁，不改已写死的九次结论。

## 2026-11-09 · 留一域与 β 上界：先查值不值得训

主题：策略改成 episode 级 β 之前，哪些事实已经能定，哪一步先做。

结论：

1. 范围写成「多产线钢板的少样本导入」。钢板族内类别空间共享，留一域评测成立；换缺陷定义的产品只保留「原型 + 支持集」这种开放标签空间，不把当前策略写成通用检测器。
2. 训 β 之前先做无训练上界：冻结 layer4，每个来源用自己的标签选最优 β，和固定 0.25 比准确率与 Δhard。差距不超过 MDE，就停，环带权重不是瓶颈。这个上界用了该来源标签，只能当上界，不能当方法结果。
3. 环带含背景。验收必须绝对准确率和 Δhard 同时过，只过一个不算。
4. 工况不作主输入。缺测维数值是 0，mask 也是 0，进编码前乘掉；exposure 全部来源都缺。surface 按来源手写，多数取值互斥，NEU 与 XSDD 的 surface 都是 1.0。
5. core/ring 没有掩码就算不了。工业路径直接丢弃无掩码图。XSDD 三个划分掩码都是 0，不进这条路径。训练路径缺掩码时退回整图均匀池化，那不是 core/ring。
6. `config/cspd/cspd.yaml` 的验证：铸坯已从验证去掉。7 个类的支持与查询来自不同来源；crack 只有 NEU，因留出开关仍进池，这一类是来源内。一次 5-way 验证里两类方式可以同时出现。同源配置 `cspd_same.yaml` 的验证全部是来源内。

依据：`output/STEEL_holdout_CAST_align/data_summary.json`；`cspd/data.py` 的 `_episode_pool` / `_take`；`cspd/frozen_contrast.py`、`cspd/target_shot.py`；`cspd/condition_io.py` 的 `apply_cond_mask`。训练集 8 类 × 6 来源（不含铸坯）共 4402 张，XSDD 694 张无掩码。

ARM 出处已核对：Marvin Zhang, Henrik Marklund, Nikita Dhawan, Abhishek Gupta, Sergey Levine, Chelsea Finn. Adaptive Risk Minimization: Learning to Adapt to Domain Shift. NeurIPS 2021. arXiv:2007.02931。它用无标签目标批次做测试时适配，和「集合统计驱动适配」同族；不是带标签的 k-shot 原型。

后续：先做逐来源 oracle-β。上界不够就转局部表示，不训 β_D。上界够了再训：无掩码可算的支持集统计、一个标量、从 0.25 附近出发、`adapt_steps=0`、外层只用留出来源的查询分类，每个来源单独训。

## 2026-11-09 · 策略网络与留一域：哪些能接上现架构

主题：MLP 当低维控制器、支持集统计、留一来源外层损失，能否把现有模型训成通用缺陷检测。

结论：

1. MLP 够用，只限输出低维适配强度。现有 `PolicyNet` 已经是两层 MLP，最后一层零初始化；不够的地方是它还对每类输出 128 维通道门控，并且内循环会在支持集上改 1×1 投影。
2. 策略输入并不是只有工况。`_class_state` 已拼接整集外观、该类特征均值、工况、类内离散度和 FiLM 残差。缺的是 core/ring 集合统计；多出来的 128 维类均值会让控制器记住类别长相。
3. 留一来源、外层只用查询分类、主损失不用原型距离对齐，这三点和现有证据一致。当前铸坯留出是整次训练固定留出，训练外层损失看不到铸坯，所以验证 0.837、测试 0.472。
4. 这条线能做的是：冻结 layer4 的双区域分数上，用支持集一次预测 `β_D`，和固定 `β=0.25` 比。它学不会脱离支持集、换缺陷定义仍成立的通用检测器。工业交付继续用固定 β。

依据：`cspd/policy.py`、`cspd/model.py` 的 `_class_state` 与 `adapt_steps`；`source_proto` 实际是带查询标签的类内拉近，不是跨来源原型对齐。铸坯上 {0.25, 0.5} 的 Δhard 差小于 MDE。

后续：未开实验。若做，只在工业 core/ring 打分上加 episode 级 `β_D`，`adapt_steps=0`，去掉 `source_proto`；CR7/GC10/NEU 各做一次完全留出，支持集统计不看查询。

- 不称通用钢板元学习框架；不与检测 mAP / MVTec 乱比。
