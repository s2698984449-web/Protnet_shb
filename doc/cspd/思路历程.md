# 思路历程（阶段性收敛）

## 2026-11-13 — 题是钢板新产线少样本导入，不是通用检测；元学习用的是 episodic 训练，不是「产线每天换任务」

主题：理论是否站得住、做通用检测还是钢铁应用、和生产是否相符、多产线厂为什么还要元学习。

结论：继续做，但把题收成 **钢板表面缺陷的新产线少样本导入**。不是通用缺陷检测。不是 MAML 那种「从任务分布里抽样、内环解冻骨干」。生产上符合的是：新产线 / 新相机 / 新钢种刚投产时，每类只有几张带掩码的标注，要用其他已有产线学过的比较方式，在本产线自己的支持图上建原型。厂里往往有多条线，正因如此才有「别的线有历史标注、这条线几乎没有」；少样本的单元是 **新线**，不是把全厂合成一条线。全开跨来源对齐同名类，和这条导入协议不一致，留出下降已经说明那套叙事弱。站得住的是：冻结骨干、学投影、同源 k-shot、core/ring。站不住的是：跨产线同名即同类、策略网络已证明有用、这是通用元学习检测器。

依据：工业基线写明范围是多产线钢板少样本导入；P1 留出整源；全开跨来源升、留出降；exact 只有冲孔。

后续：开题与论文主叙事用导入协议。元学习只作为 episode 训练与原型分类的工具。不要把「多产线厂」解释成「所以要跨域对齐所有同名文件夹」。

### 4. 组怎么划，episode 怎么抽

| 规则 | 内容 |
|---|---|
| 组文件 | `<类>/<来源>/groups.json` |
| GC10 | 文件名 `img_<类>_<批次>_<序号>` 的批次号，是产线批次 |
| 其余来源 | 32×32 灰度、8 档直方图，L1 距离小于 0.3 聚成簇，不是卷号 |
| 划分 | 整组进 train 或 val 或 test，比例 0.6/0.2/0.2，种子 0 |
| 加载 | 磁盘不预裁；读图时 `crop_to_mask`，margin 0.35，最短边 96，正方形，再 224 |
| 分数 | 冻结骨干 + layer3 的 core/ring，`s = cos_core + 0.25·cos_ring` |
| 同来源 episode | 查询来源内部抽类；n_way 上限 5，k∈{3,5}（0.7/0.3），q=8 |
| 严格分组 | 一整组只进 support 或只进 query，组不够则该类不可行，n_way 跟可行类走 |
| 留出 | 训练/验证不见该来源；测试支持和查询都在留出来源，`holdout_pool=all` 可读三个划分 |
| 跨来源 | 由 ρ 控制；现行关闭组 ρ=0。打开时默认同名文件夹即可，v3 曾限制 `cross_classes: [punch]` |
| 困难对 | 现行协议用训练来源验证集的**同源**混淆，只改类别组成，不改损失 |

组数两极（目录内合计）：GC10 冲孔 219 张 / 151 组；CR7 压痕 dent 600 张 / 16 组。XSDD 温度系氧化皮、辊印各 203 张 / 3 组。

### 5. 目前主要问题在哪

| 优先级 | 环节 | 判断 | 证据 |
|---|---|---|---|

## 2026-11-09 · 留一域与 β 上界：先查值不值得训

主题：策略改成 episode 级 β 之前，哪些事实已经能定，哪一步先做。

依据：`output/STEEL_holdout_CAST_align/data_summary.json`；`cspd/data.py` 的 `_episode_pool` / `_take`；`cspd/frozen_contrast.py`、`cspd/target_shot.py`；`cspd/condition_io.py` 的 `apply_cond_mask`。训练集 8 类 × 6 来源（不含铸坯）共 4402 张，XSDD 694 张无掩码。

ARM 出处已核对：Marvin Zhang, Henrik Marklund, Nikita Dhawan, Abhishek Gupta, Sergey Levine, Chelsea Finn. Adaptive Risk Minimization: Learning to Adapt to Domain Shift. NeurIPS 2021. arXiv:2007.02931。它用无标签目标批次做测试时适配，和「集合统计驱动适配」同族；不是带标签的 k-shot 原型。

后续：先做逐来源 oracle-β。上界不够就转局部表示，不训 β_D。上界够了再训：无掩码可算的支持集统计、一个标量、从 0.25 附近出发、`adapt_steps=0`、外层只用留出来源的查询分类，每个来源单独训。

## 2026-11-09 · 策略网络与留一域：哪些能接上现架构

主题：MLP 当低维控制器、支持集统计、留一来源外层损失，能否把现有模型训成通用缺陷检测。

结论：

1. MLP 够用，只限输出低维适配强度。现有 `PolicyNet` 已经是两层 MLP，最后一层零初始化；不够的地方是它还对每类输出 128 维通道门控，并且内循环会在支持集上改 1×1 投影。
2. 策略输入并不是只有工况。`_class_state` 已拼接整集外观、该类特征均值、工况、类内离散度和 FiLM 残差。缺的是 core/ring 集合统计；多出来的 128 维类均值会让控制器记住类别长相。
3. 留一来源、外层只用查询分类、主损失不用原型距离对齐，这三点和现有证据一致。当前铸坯留出是整次训练固定留出，训练外层损失看不到铸坯，所以验证 0.837、测试 0.472。
4. 这条线能做的是：冻结 layer4 的双区域分数上，用支持集一次预测 `β_D`，和固定 `β=0.25` 比。它学不会脱离支持集、换缺陷定义仍成立的通用检测器。工业交付继续用固定 β。

依据：`cspd/policy.py`、`cspd/model.py` 的 `_class_state` 与 `adapt_steps`；`source_proto` 实际是带查询标签的类内拉近，不是跨来源原型对齐。铸坯上 {0.25, 0.5} 的 Δhard 差小于 MDE。

后续：未开实验。若做，只在工业 core/ring 打分上加 episode 级 `β_D`，`adapt_steps=0`，去掉 `source_proto`；CR7/GC10/NEU 各做一次完全留出，支持集统计不看查询。

## 2026-11-09 · 同源与铸坯留出重训

主题：layer4 可训的元训练，相对冻结双区域原型，还要不要当成交付。

结论：同源测试准确率 0.903，铸坯留出测试 0.472（3-way 随机 0.333）。留出仍停在早先 0.43～0.48，验证高（0.837）只说明见过来源。交付继续用冻结 layer4 + 同产线 3～5-shot + β=0.25，分母 CR7/GC10/NEU 的 Δbg/Δhard；episode 准确率不与这套分数混比。仓库没有 ProtoNet / Matching / Relation 的同协议数。

依据：`output/STEEL_same_l4/train.log`、`output/STEEL_holdout_CAST_align/train.log`；工业数字见 `output/STEEL_industrial_proto/industrial_proto.json`。

后续：不把这次重训写成跨域已解决。要动交付，仍按协议卡的 Δbg/Δhard，而不是把训练准确率往上抬。

## 2026-11-07 · 主线收敛为工业少样本基线

主题：训练栈与表示探针是否继续。

结论：

1. 元训练在「见过来源」上可高（同来源≈0.87、见过换源≈0.80），**真留出产线弱**（铸坯≈0.43）。
2. 距离校准、投影、浅层、DINO、patch 均未改写「跨域共享缺陷语义不足」的判断。
3. 冻结 layer4 + 同产线 3～5-shot + `d_core+0.25·d_ring` 在 CR7/GC10/NEU 上 **gate 通过**。
4. 仓库收敛为该交付基线；旧训练权重、探针脚本与中间产物删除。下一步优化另立项，不默认重开表示实验。
