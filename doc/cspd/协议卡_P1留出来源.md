# 协议卡 · P1 留出来源

状态：2026-11-10 写定。`data/new_split_v3` 已按组划出。三件关闭的九次已跑完：留出准确率 NEU 0.810、CR7 0.539、GC10 0.614（各种子平均）。工业交付仍以 [协议卡_目标域少样本.md](协议卡_目标域少样本.md) 和 [阶段性基线.md](阶段性基线.md) 为准。本卡不覆盖那份锁定结果，也不改 `output/STEEL_industrial_proto/`。

类等价标准见 [类等价评判标准.md](类等价评判标准.md)。现有数据里锁定的 exact 只有冲孔一对，而且是双来源。跨来源评估不再作为主结果。

课程文档第八节里的 A/B/C 是「无课程 / 有课程 / 策略网络」，和本卡的 A、C 不是同一组实验。下面的字母只在本卡里使用。

## P1（主）

留出一个来源。训练和验证都不使用它的任何图像。评估时，支持集和查询集都来自这个来源。

类不需要和其他来源同名或等价。留出来源里，张数够做成 k-shot 的类都进入评估，包括只在这一个来源出现的类。

它回答的问题是：模型在其他产线上学过怎样比较缺陷之后，到一条新产线，每类给几张标注，能不能用。

已有的同源 0.835 是训练时见过该来源的数字，不是 P1。带 CSU 的 v2 数字不能当留出结果引用。CSU 的 train、val、test 都进过 `STEEL_curriculum_v2`。S3D 同样进过 v2。这两折即使按 P1 重训，也只称开发阶段证据。

### 试点范围

来源：NEU、CR7、GC10。每折 3 个种子：0、1、2。先做这 9 次，不把其余来源一次铺开。

k 主报 3，附报 5。查询张数与工业协议同一套支持/查询分离：按伪批次分开，支持图和查询图不来自同一簇。

### 训练怎么停

目标来源不参与选模型。三折共用一个在开训前写死的迭代数，不用目标域的 loss 或准确率来选。

迭代数若要改，只许用训练来源内部的验证，并且三折用同一个数。看过某一折的目标域结果之后，不再改这个数。

layer4 保持冻结。β=0.25。策略网络不开。不加位置损失、对齐损失、通道门控。

### A 和 C

- **A**：冻结 ImageNet ResNet18 layer4，不在钢板上训练，不用投影。分数与工业协议相同：`core` 加 `0.25 × ring`，`d = 1 - cos`。CR7、GC10、NEU 上已有 k=3 的缺陷准确率和 Δbg（0.656 / 0.115，0.588 / 0.159，0.937 / 0.170）。那是旧划分上的 A，可以引用方法，不能直接当成这次配对的 C−A。
- **C**：在其余来源上训练。评估时使用它自己的投影。骨干仍是冻结 layer4，区域和 β 与 A 相同。

配对时，A 和 C 用同一批支持图和查询图。各来源报告 C−A，附按图像重抽样的 2.5%～97.5% 区间。

现行课程若只训练投影、评估却不用投影，C 和 A 的分数会相同，对照没有信息。所以 C 的评估必须带上这个投影。这一差解释的是「其他产线上的投影有没有帮助」。这一步不解冻 layer4。`doc/cspd/待做.md` 里「全冻结对 layer4 解冻」是另一个对照，不在本试点里做。

### 指标

每个留出来源、每个种子：

1. 缺陷准确率。
2. Δbg：缺陷准确率减对称画布上的贴块背景。定义与工业协议卡相同。
3. C−A 的配对差，带图像自助区间。

单来源类和跨来源类分开列张数，都进 P1 的总数。P1 的通过与否不依赖等价类。

区间下界大于 0，记该来源上 C 高于 A。三折不必全部为正才把问题算作已回答。有的来源为正、有的不为正，就按来源写。

### 划分

`data/new_split_v3` 已生成，`data/new_split` 保留不动。GC10 用文件名批次号整组划分。其余来源没有核对过的卷号，用 32×32 灰度直方图聚簇，不编造卷号。组号在各类来源目录的 `groups.json`，统计在 `merge_report.json`。等价等级仍是临时的，这批目录只服务 P1。

留出评估读取该来源的 train、val、test，支持图和查询图来自不同组。直方图簇不是卷号；簇很大时，分离的是簇，不是产线批次。XSDD 三种外观接近的类簇太大，测试划分为 0，且无掩码，训练配置排除。

## 类的角色

跨来源正表只有冲孔（GC10、CR7），两边都是圆孔。划痕、夹杂、氧化皮、油污、折痕只写「名称对齐」，不写已等价。单来源类，例如 NEU 麻面、CR7 局部坑、GC10 丝斑，只出现在来源内那一栏。清单见 `config/cspd/class_manifest.yaml`。

评估分两栏：来源内是留出后用该来源自己的支持图；跨来源正表目前只有冲孔。两栏不加成一个准确率。

## P2（辅）

支持集来自其他来源，查询来自留出来源。只有这时才用类等价。

- exact：目前只有冲孔（GC10、CR7）。单独成表。
- related：划痕、夹杂、氧化皮、油污、折痕。表头写「名称对齐，未严格等价」。
- incompatible 和单来源类不进 P2。

P2 不写进主结论，也不和 P1 的准确率放在同一张表。
