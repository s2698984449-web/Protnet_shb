## 全量方法跑

三件一起打开，评估仍是留出来源。数据是 `data/new_split_v3`。留出 NEU、CR7、GC10，各 3 个种子。留出的那一家不进训练和验证。XSDD 排除。layer4 冻结。迭代 200，不按留出域早停。

有掩码且张数够「3 或 5 张支持 + 8 张查询」的类都进训练池，不按等价等级删类。留出 NEU 时，能组成跨来源 episode 的是：划痕（铸坯、CSU、S3D）、夹杂（CR7、GC10、中厚板、CSU）、氧化皮（中厚板、S3D）、油污（CR7、GC10）、折痕（GC10、钢管）、冲孔（CR7、GC10）。只在一个来源里的类走该来源内部的 episode。CSU 氧化皮在 `oxide_scale_csu`，12 张，抽不到。未映射的 CSU 辊印、弹性形变、浪形，S3D 的 `in`、`wr`、`rust`，以及钢轨，不在目录里。

每个 episode 最多 5 类，每类支持 3 张（70%）或 5 张（30%），查询 8 张。一个更新步 4 个 episode，梯度累积 2 次。损失只算查询集交叉熵。跨来源时查询在一个来源，支持在另一个同名来源；该类只有一个来源时退回内部抽取。支持图和查询图不同组。

| 迭代 | ρ | β |
| --- | --- | --- |
| 1–50 | 0.30，先抽特征接近的来源 | 冻在 0.25 |
| 50–150 | 升到 0.80，来源由近到远；150 之后加入训练来源验证集上的困难类对 | 第 50 步起可训，输出在 0 到 0.5 |
| 150–200 | 保持 0.80 | 按当前支持集输出 |

分数是 `cos(core) + β · cos(ring)`。投影可训练。β 来自支持集统计加该来源的工况和缺失标记，不看查询图和查询标签。没填的工况槽记为缺失。工况表与三件关闭时相同，CSU、S3D 的亮度不另改。配置是 `config/cspd/curriculum_full.yaml`。验证每 5 步把同来源和跨来源分开，不看留出来源。结束时用最后的权重测留出来源，分数带上投影和这一批支持集的 β。主结果是这次减去三件全关的 P1，并报 Δbg。日志里 β 在第 50 步之后离开 0.25，ρ 升到 0.80。

## 总原则

第一版目标不是直接学出「完全不需要目标域样本」的通用模型，而是：

> 训练阶段持续遇到来源变化；测试时给目标域 3～5 张支持图，模型能根据支持集统计调整缺陷判别。

工业基线仍保持：

```text
冻结 layer4
目标域 3～5-shot
score = cos(core) + 0.25 × cos(ring)
```

（与距离形式 `(1-cos)+β(1-cos)` 在 argmax/argmin 下等价。）课程学习是研究线，单独和固定 `β=0.25` 对比。

## 一、Episode 怎么构造

每个 episode 包含：

```text
query source Q
query classes C(Q)
support set
query set
```

### 1. 查询来源

均匀选择来源，而不是按图片数量抽样。初版可用来源（有掩码）：

```text
CR7、GC10、NEU、PLATE、PIPE、CAST
```

留一来源验证时，该来源不能进入训练。XSDD 因无掩码排除。RAIL 未入库。CSU、S3D 已进入可采样来源。

### 2. 查询类别

从查询来源中选择类别：

```text
n_way = min(5, 当前来源拥有的类别数)
```

查询集全部来自同一个来源 `Q`，避免一个 episode 内查询来源本身成为分类捷径。

### 3. 支持来源

每个类别单独选择支持来源：

```text
support_source(c) ∈ 其他来源中包含类别 c 的来源
```

支持图像必须和查询图像不重叠。

如果某个类别只有一个真实来源（当前 `纵向裂纹` 只有 CAST）：

- 不进入主要的真实跨来源 episode；
- 可以加入增强产生的虚拟来源；
- 虚拟来源不能算作真实来源，也不能用来宣称跨域成功。

这点很重要：目前裂纹的跨域问题首先是数据覆盖不足，采样器本身解决不了。Rail 仍未入库。CSU 和 S3D 没有纵向裂纹类，补不了这一类。

## 二、课程阶段

定义：

```text
ρ = 跨来源 episode 占比
```

| 训练进度 | 同来源 | 跨来源 | 目的 |
|---|---:|---:|---|
| 0～25% | 70% | 30% | 先保持当前分类能力 |
| 25～75% | 从 70% 降到 20% | 从 30% 升到 80% | 逐步增加跨域难度 |
| 75～100% | 20% | 80% | 充分训练跨来源泛化 |

跨来源难度也分阶段（v2 已接上：训练时按冻结 layer4 距离先近后远；进度 75% 之后插入验证集上的困难类对。验证和测试不走这两段，避免指标跟着课程变）：

1. 先采样冻结特征空间中比较接近的来源；
2. 中期逐渐加入中等距离来源；
3. 后期加入最远来源；
4. 后期再加入训练来源验证集统计出的困难类别对。

困难类别对只能来自训练来源验证集，不能用 CAST 或最终测试混淆矩阵设计。

## 三、每个优化步的组成

初版固定：

```text
meta_batch = 8 个 episode
每类支持数 k = 3，概率 70%
每类支持数 k = 5，概率 30%
每类查询数 q = 8
```

显存不足时：

```text
meta_batch = 4
梯度累积 2 次
```

一个优化步必须尽量包含多个不同查询来源，不能一次只看一个来源。

## 四、策略网络初版

### 只输出一个 episode 级 β

第一版不同时学习通道门控、每类权重、拒识阈值和复杂温度。否则无法判断究竟是课程采样有效，还是策略网络过强。

```text
β = 0.25 + 0.25 × tanh(u)
→ 0 ≤ β ≤ 0.5
```

最后一层零初始化，训练初始状态就是 `β = 0.25`，与已验收工业基线一致。

### 策略网络输入

不输入查询图像，也不输入查询标签。输入只来自支持集的集合统计：

```text
core 特征均值和方差
ring 特征均值和方差
core-ring 相似度
类内离散度
类间原型间隔
支持集数量
工况编码
工况是否缺失的 mask
```

第一版只使用低维统计，不直接输入每个类别的 128 维均值，避免网络记住「这个类别长什么样」，而不是判断「当前域偏移了多少」。

```text
统计向量 → Linear(64) → ReLU → Linear(32) → ReLU → Linear(1) → β
```

### 暂时不做

```text
不输出每类一套 β
不输出 128 维通道门控
不输入查询特征
不做支持集上的梯度更新
adapt_steps = 0
```

`τ` 暂时固定为 1。只有当 β 单独实验通过门禁后，再增加窄范围温度参数。

## 五、推理打分

对每个类别建立两个原型：

```text
p_core(c) = 支持集中 core 特征均值
p_ring(c) = 支持集中 ring 特征均值
```

查询样本对类别 `c` 的得分：

```text
s(c) =
    cosine(q_core, p_core(c))
    + β_episode × cosine(q_ring, p_ring(c))
```

分类：`argmax s(c)`。

- core 和 ring 分别归一化；
- β 是整个 episode 一个值；
- 不再为每个类别单独预测 β；
- 查询标签只进入损失，不进入策略输入。

---

## 六、损失函数

第一版只使用查询集分类交叉熵。分别计算：

```text
L_intra：同来源 episode 的查询损失
L_cross：跨来源 episode 的查询损失
```

总损失：

```text
L = (1 − ρ) L_intra + ρ L_cross
```

`ρ` 是课程阶段给出的跨域比例。用 episode 数量比例控制影响，而不是给跨域损失加一个很大的固定系数。

同时：每个 episode 内先平均；每个 episode 权重相同；梯度裁剪 `max_norm = 1.0`。

### 第一版关闭的损失

```text
source_proto_weight = 0
location_loss_weight = 0
额外对比损失 = 0
额外 margin loss = 0
```

位置损失后续单独做 `0 vs 0.5`，不能和策略网络、课程采样同时首次加入。

## 七、训练阶段

### 阶段 A：表示稳定（前 25%）

```text
策略网络冻结
β = 0.25
layer4 冻结
训练投影层（初版 dual-region 路径不接旧 FiLM，避免和通道门控混在一起）
跨来源比例从 30% 开始
```

### 阶段 B：放开策略网络（25% 之后）

```text
放开 β 策略网络
策略网络学习率 = 主训练头学习率的 0.3 倍
layer4 仍然冻结
跨来源比例逐步提升到 80%
```

### 阶段 C：困难跨域（最后 25%）

```text
跨来源比例固定 80%
加入远来源 / 困难类对（后加）
同来源 episode 保留 20%
```

## 八、必须做的三组对照

| 实验 | 课程采样 | 策略网络 | 用途 |
|---|---|---|---|
| A | 否 | 否，固定 β=0.25 | 当前工业基线对照 |
| B | 是 | 否，固定 β=0.25 | 判断课程采样是否有效 |
| C | 是 | 是，预测 β | 判断策略网络是否额外有效 |

只有 C 超过 B，才能说策略网络有贡献。若 B 已提升而 C 没有，说明主要收益来自训练 episode 设计，而不是 MLP 策略。

## 九、验收标准

留一来源验证：一个来源完全不参与训练。至少 5 个随机种子，固定验证 episode。

必须同时检查：跨来源绝对准确率、每类召回、裂纹单独召回、Δbg/Δhard、同来源准确率、β 的分布。

通过条件：

1. 至少两个留出来源绝对准确率提升；
2. Δhard 超过现有 MDE；
3. 同来源性能不能明显下降；
4. β 不能长期贴在 0 或 0.5 边界；
5. 提升不能只来自某一个来源或某一个类别。

如果只提升 Δbg、绝对准确率不变，结论只能是「相对背景改善」，不能称为跨域检测能力提升。若整套方案仍抬不高裂纹，结论是真实来源覆盖不足，需先补至少两个独立裂纹来源。
