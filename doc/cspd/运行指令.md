## 留出队列

产物都在 `output/cspd/` 下，按改动批次分子目录。v1 是三件关闭，权重已删，数字在实验记录。v2 是 ρ 到 0.80 的全开。v3 是当前要跑的：ρ 固定 0.20，跨来源只允许冲孔，β 固定 0.25，每个留出来源只跑种子 0。

```powershell
cd "D:\元强化学习\代码"
D:\miniconda3\envs\MAML\python.exe scripts/run_p1_queue.py
```

三次目录是 `output/cspd/v3/NEU/`、`output/cspd/v3/CR7/`、`output/cspd/v3/GC10/`。已有 `last.pt` 会跳过。退出码不是 0 时停住。
