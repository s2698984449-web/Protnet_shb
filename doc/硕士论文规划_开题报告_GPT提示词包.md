## 六、常见问题与解决方案

### Q1：开题报告字数不够怎么办？

**策略**：
1. 研究背景可以扩展到行业背景（引用行业报告数据）
2. 国内外现状可以分小节写得更细
3. 技术路线部分增加详细的公式推导
4. 可行性分析可以写得更详细（理论+实践+数据+代码四个维度）

### Q2：创新点不够突出怎么办？

**策略**：
1. 每个创新点要对应具体的"问题-方法-效果"链条
2. 用对比的方式突出创新性（现有方法A vs 本文方法B）
3. 用数字量化创新贡献（+3.5%、+2.0%等）
4. 创新点之间要有逻辑关联，不能是简单的并列

### Q3：参考文献数量不够怎么办？

**策略**：
1. 增加中文期刊文献（《计算机学报》《自动化学报》《软件学报》《仪器仪表学报》《东北大学学报》《计算机研究与发展》等）
2. 增加近2年的顶会论文（CVPR/ICML/NeurIPS/ECCV 2025/2026）
3. 增加工程类期刊文献（IEEE Transactions on Industrial Informatics等）
4. 增加综述类文献（少样本学习综述、工业缺陷检测综述等）

### Q4：实验数据不够怎么办？

**策略**：
1. 先跑基线实验（ProtoNet / MAML），作为对比基础
2. 消融实验可以分批次做，每加一个模块就跑一次
3. 对比实验可以引用文献中的已有结果（需要标注来源）
4. 如果时间紧，可以先做小规模实验（如50个episode），答辩时说明是初步结果
