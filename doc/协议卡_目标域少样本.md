# 协议卡 · 目标域少样本（基线）

与 [阶段性基线.md](阶段性基线.md) 对齐。

## 定稿

1. **特征**：冻结 ImageNet ResNet18 layer4；不训练投影/适配器。
2. **区域**：`core`=mask 内；`ring`=膨胀 16px 减 core；远背景只作贴块基线对照。
3. **分数**：`d_core + β·d_ring`，`d=1-cos`；**β=0.25**（铸坯开发集锁定）。
4. **支持**：目标域每类 k∈{3,5}；与查询按伪批次（图像统计聚类）分离。
5. **主指标**：Δbg、Δhard（缺陷准确率 − max(贴块背景, 几何)）；附报混淆。
6. **分母**：CR7、GC10、NEU（NEU 框占比≤0.5，丢 pit）。CAST 仅开发选参。
7. **区间**：图像自助 2.5%～97.5%；≥20 组支持集。
8. **跨来源支持**：附录；不作交付卖点。

## 通过（已满足于 industrial_proto）

- β 在 k=3/5 无排序反转  
- 分母三来源 Δbg 正向  
- 至少两来源 Δhard 区间下界 > 0（实测三来源均过）  
- NEU 跨 0 则标风险、不再调距离（实测未跨）
