# 运行指令

在仓库根目录执行。算法和脚本都是通用的：换数据只改 `config/cspd.yaml` 里的绝对路径和可选旁路，不另写数据集脚本。

数据目录形状：

```text
<绝对路径>/
  类别A/
    来源1/
    来源2/
  类别B/
```

`cross_source: true` 时，同一类的支持集和查询集来自不同来源子目录。`source_slot` 把来源名写进指定工况槽。`mask_root_train`、`mask_root_val`、`mask_root_test` 按划分覆盖 `mask_root`。

钢板这次的合并：

```text
python scripts/merge_sources.py --config config/steel_sources.yaml
python scripts/load_data.py --config config/cspd.yaml
python scripts/train_cspd.py --config config/cspd.yaml
```

映射表在 `config/steel_sources.yaml`。原始类名在那里改，不改采样代码。

## 1. 闭环怎么接

```text
类别图 ──► train/val/test 绝对路径
产线工况 JSON（可选）──► condition_file
亮度脚本 CSV（可选）──► illumination_manifest → illuminance 槽
掩码目录（可选）──► mask_root + mask_pattern
还原图目录（可选）──► restored_root   # 扩散或亮度校正结果
                │
                ▼
         通用 episode 采样
                │
                ▼
  原图特征 + 还原图特征(FiLM) + 按类策略 + 掩码高斯原型
                │
                ▼
     分类损失 + 可选定位损失
                │
                ▼
     早停只看 val_dir；test_dir 最后报一次
```

没有旁路时自动降级：缺测槽位不进编码；无掩码则均匀建原型且定位损失为 0；无还原图则还原支路等于原图。

## 2. 常用命令

```text
python scripts/split_class_folder.py --input 类别根目录 --output 输出根目录 --train 0.34 --val 0.33 --test 0.33
python data_proc/compute_illumination.py --input 图像目录 --output 结果目录 --group all
python scripts/load_data.py --config config/cspd.yaml
python scripts/train_cspd.py --config config/cspd.yaml --iters 20
python scripts/train_cspd.py --config config/cspd.yaml
python scripts/infer_cspd.py --config config/cspd.yaml --ckpt output/RUN_v1/best.pt
```

对照只训投影：

```text
python scripts/train_cspd.py --config config/cspd_test.yaml --iters 20
```

`exp_name` 决定输出目录。推理的 `--ckpt` 用 `output/<exp_name>/best.pt`。

## 3. 命令行参数

| 脚本 | 参数 | 默认 | 作用 |
| --- | --- | --- | --- |
| `scripts/split_class_folder.py` | `--input` / `--output` | 必填 | 类别根目录与输出根目录 |
| | `--train` `--val` `--test` | `0.5/0.25/0.25` | 比例，和为 1 |
| | `--link` | `hard` | `hard` / `symlink` / `copy` |
| `scripts/load_data.py` | `--config` | `config/cspd.yaml` | 检查数据 |
| `scripts/train_cspd.py` | `--config` | `config/cspd.yaml` | 配置 |
| | `--iters` / `--eval-tasks` / `--device` | 用配置 | 覆盖这一次运行 |
| `scripts/infer_cspd.py` | `--ckpt` | 必填 | 权重 |
| | `--tasks` / `--device` | 用配置 | 评估次数与设备 |
| `data_proc/compute_illumination.py` | `--input` `--output` | 必填 | 亮度计算 |
| | `--group` | `all` | `all` 或 `child` |
| | `--reference` | `all` | 定标准用的相对路径 |
| | `--thumb` / `--max-shift` | `16` / `40` | 缩略边长与最大加减 |

## 4. 配置参数

### 路径与类别

| 键 | 含义 |
| --- | --- |
| `exp_name` | 输出目录名 `output/<exp_name>/` |
| `train_dir` / `val_dir` / `test_dir` | 类别文件夹绝对路径。`early_stop=true` 时 `val_dir` 必填 |
| `include_classes` | 只保留这些类；空列表表示不限制 |
| `exclude_classes` | 排除这些类 |

### 工况槽位

| 键 | 含义 |
| --- | --- |
| `cond_slots` | 槽位名列表。默认六槽：材料、表面、照度、灯型、曝光、相机 |
| `cond_dim` | 必须等于槽位个数 |
| `condition_file` | 可选 JSON：`相对路径 -> {槽位: 数值}` |
| `illumination_manifest` | 可选 CSV（亮度脚本产出），用 `offset` 填 `illuminance` |
| `cond_fallback_image_stats` | `illuminance` 仍缺测时，是否用灰度均值补位 |
| `illuminance_offset_scale` | 把亮度偏移压到约 `[-1,1]` 再映到 `[0,1]` |

### 掩码、还原图、损失

| 键 | 含义 |
| --- | --- |
| `mask_root` | 掩码根目录。空=不用掩码 |
| `mask_pattern` | 文件名模板，如 `{stem}_mask.png` |
| `use_mask_proto` | 支持集有掩码时是否用高斯加权建原型 |
| `gauss_sigma_ratio` | 高斯半径相对特征图边长 |
| `location_loss_weight` | 查询掩码质心与峰值的 L1 权重。无掩码时该项为 0 |
| `restored_root` | 还原图平行目录。空=还原支路等于原图 |

### 网络与优化

与之前相同：`feat_dim`、`film_rho`、`policy_rho`、`topk_ratio`、`adapt_steps`、`adapt_lr`、`lr`、`weight_decay`、`grad_clip`、`iters`、`eval_every`、`eval_tasks`、`early_stop`、`early_start`、`patience`、`monitor`、`min_delta`、`device`。

调试冻结见 `config/cspd_test.yaml` 的 `freeze` 段。

## 5. 输出文件

| 文件 | 内容 |
| --- | --- |
| `data_summary.json` | 各类张数、工况槽位、掩码比例 |
| `config.yaml` / `config.json` | 本次实际配置 |
| `structure.txt` | 模块参数量与网络文本 |
| `train.log` | 训练与验证日志 |
| `best.pt` | 验证集选出的权重 |
| `last.pt` | 结束时权重 |
| `infer.json` | 推理指标 |

## 6. 旁路文件格式

`condition_file`：

```json
{
  "类别A/001.png": {"material": 0.2, "illuminance": 0.55, "camera": 0.1}
}
```

未写的槽位视为缺测。

`illumination_manifest`：亮度脚本写出的 CSV，至少含 `rel_path`、`offset`。

掩码：`mask_root / <相对类别路径父目录> / mask_pattern`。例如图在 `.../train/scratch_head/000.png`，模式 `{stem}_mask.png`，则掩码为 `mask_root/scratch_head/000_mask.png`。
