## 原型几何（只推理，membership 仍用原 299）

- 分数定义：`s = cos_core + β·cos_ring`，β=0.25（fixed）。原型是该类 support core/ring 均值后再 L2 归一化，与 `DualRegionBetaDetector.forward` 一致。margin = `s_true - max_other`。
- 与已保存预测不一致：A 0 条，B 0 条。共同错误集合未因重算而替换。
- A margin 均值：都对 0.313，共同错 -0.344；B：都对 0.336，共同错 -0.313。
- A 共同错：cos_core 真类 0.180 vs 预测类 0.496；B：真类 0.226 vs 预测类 0.514。
- oil->punch 共同同错 n=11：A margin -0.677（core 真/预 -0.042/0.596）；B margin -0.592（core 真/预 -0.038/0.544）。
- punch->weld_line 共同同错 n=15：A margin -0.375（core 真/预 0.372/0.740）；B margin -0.385（core 真/预 0.334/0.713）。
- rolled_pit->fold_wrinkle 共同同错 n=14：A margin -0.508（core 真/预 0.094/0.547）；B margin -0.411（core 真/预 0.174/0.538）。
- inclusion->silk_spot 共同同错 n=28：A margin -0.265（core 真/预 0.287/0.508）；B margin -0.210（core 真/预 0.388/0.555）。
- 组均值相对类均值的余弦偏移已写入 geometry_group_offsets.csv。这是几何描述，不能直接说“该批次把原型拉偏并导致错误”。

## 假说 vs 未做

- 假说（未证实）：不均等多组 support 上，组等权会改善油污/冲孔。P1 的**必要可能性**存在（100 格中 34 格数学上可能与普通均值不同，k=5 更集中），但主导组在错误与正确参照上没有清楚分离，**不是充分理由断言 P1 会改善**。
- P1 建议条件：仅当需要直接检验该操作时再做，且必须同 episode、同特征、只改聚合；单组格子应事先知道结果不变。即使 P1 无改善，也只能说对“组等权这一操作”无证据，不能排除层特征相近或类别定义重叠。

## 焦点方向的 support 可改性（对 P1 条件很关键）

- oil→punch 共同同错 11 例：正确类（oil）support **全部是单组**（11/11），组等权与普通均值数学上相同，P1 **不能改油污原型**。最多只能改冲孔类原型。同时这 11 例的 query core 与油污原型余弦均值为负（A -0.042，B -0.038），与冲孔原型约 0.55–0.60，margin 约 -0.59 到 -0.68，间隔很大。这更支持“油污 query 的 core 特征与当前油污原型方向差得远”，而不是“油污 support 被某组拉偏”（单组时不存在组间拉偏）。
- punch→weld_line 共同同错 15 例：正确类 support 有 14/15 不均等、P1 数学上可能改冲孔原型；预测类焊缝有 8/15 为单组。
- rolled_pit→fold_wrinkle 14 例：正确类仅 3/14 可能被 P1 改变。
- inclusion→silk_spot 28 例：12/28 正确类可能被 P1 改变，但 28/28 的 max_share≥2/3（多数已被一组占主导，包括 4+1 这种）。

因此：P1 对**油污→冲孔这一主瓶颈几乎没有必要作用空间（油污原型不变）**；若仍做 P1，预期更可能影响冲孔→焊缝等子集，不能指望它单独打通油污。即使做了也无改善，只能否定“组等权”这一操作，不能排除层特征相近或类别外观重叠。
