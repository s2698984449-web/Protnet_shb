# 航空缺陷检测 — 训练方案对齐文档

> 三数据集：真实 291 张（YOLO）+ AeBAD + bladeSynth
> 当前架构：YOLO26 提特征 → 128 维投影 → MAML 融合分类
> 核心瓶颈：小缺陷占比极小 + 整图 GAP 稀释信号

---

## 一、总体策略：三阶段，不要混用

```
Phase 0  通用特征预训练     bladeSynth + AeBAD(正常)     → aviation_backbone.pt
Phase 1  MAML 元学习         真实291 + AeBAD(缺陷转分类)   → MAML checkpoint
Phase 2  解冻微调 backbone   同上，小学习率               → 最终模型
```

| 数据集 | 角色 | 能否进 MAML meta-train | 原因 |
|--------|------|------------------------|------|
| bladeSynth 12500 | Phase 0 预训练 | ❌ 不进 | 合成域，domain gap 大 |
| AeBAD 1228正常+4342异常 | Phase 0 + Phase 1 | ✅ 转换后进入 | 与真实叶片高度相似 |
| 真实 291 张 | Phase 1 主评估集 | ✅ 核心 | 最终泛化目标 |

原则：
- bladeSynth 只教 backbone「认识叶片和缺陷形态」
- MAML 只在真实 + AeBAD 上学跨域小样本
- domain_3（试件 20–26）永远不参与预训练和 MAML 训练

---

## 二、统一缺陷 taxonomy（三源对齐）

项目已定义 4 类，固定映射如下：

| 统一类 | 文件夹 | AeBAD | bladeSynth | 真实 YOLO |
|--------|--------|-------|------------|-----------|
| 0 划痕 | 0_scratch | groove | scratch | scratch |
| 1 污染 | 1_contamination | — | corrosion | dirty/stain/dot |
| 2 折痕 | 2_crease | — | — | crease（极少） |
| 3 损伤 | 3_damage | ablation/breakdown/fracture | nick/dent | damage |

说明：
- AeBAD 无「正常类文件夹」：正常样本单独放 0_normal 或预训练专用目录
- 不要和 4 缺陷类混在同一 N-way task 里，除非做 5-way

## 三、数据分布怎么设

### 3.1 Phase 0 预训练（新建，当前代码还没有）

目标：让 YOLO26 backbone 学会「叶片 + 小缺陷纹理」，而不是 ImageNet 的通用物体。

数据池：

| 来源 | 用量建议 | 标签形式 |
|------|----------|----------|
| bladeSynth | 全部 ~12500 | 原生 5 类分类 |
| AeBAD train/good | 554 张 | 「正常」二分类 |
| AeBAD test 缺陷 | 可选 20% 做 crop 辅助 | 4 类（用 mask 裁 ROI） |
| 真实 291 | 0 张 | 完全留出 |

训练任务（推荐多任务，一个 backbone）：

1. 主任务：bladeSynth 5 类全图分类（CrossEntropy）
2. 辅任务：AeBAD 正常 vs 异常二分类（只用 crop 或全图）
3. 可选：SupCon / Triplet，同类缺陷拉近、跨类拉远

划分：

```
pretrain/
├── bladesynth/          train 90% / val 10%（按渲染 seed 分，不按类分）
├── aebad/
│   ├── normal/          train/good 全部
│   └── defect_crops/    test 四类，按 defect_type 分层 val 10%
```

注意：
- 不要把 AeBAD 的 background/illumination/same/view 子集当 4 个 domain 放进预训练 val
- 那是域偏移测试集，应留给 MAML 或最终评估

---

### 3.2 Phase 1 MAML（在现有 data/aviation/ 上扩展）

当前：domain 0–2 训练，domain 3 测试（试件 hold-out），每域 ~60–100 张，有效 2 类。

建议扩展为 8 个 domain：

| domain | 内容 | MAML 角色 |
|--------|------|-----------|
| 0, 1, 2 | 真实试件 1–19（不变） | meta-train |
| 3 | 真实试件 20–26 | meta-test（金标准） |
| 4 | AeBAD → ablation 转 3_damage | meta-train |
| 5 | AeBAD → breakdown 转 3_damage | meta-train |
| 6 | AeBAD → fracture 转 3_damage | meta-train |
| 7 | AeBAD → groove 转 0_scratch | meta-train |

配置：
- train_domains：0,1,2,4,5,6,7
- test_domain：3（只用真实 held-out，最能反映真实泛化）

AeBAD 正常样本：每个 defect domain 里可放少量 0_normal 作负样本，或单独 domain_8；
ways=2 时 task 从「scratch vs damage」或「normal vs damage」里采样。

采样权重（解决类别失衡）：

```
真实 defect 样本：权重 ×3（稀缺金数据）
AeBAD 每类 defect：权重 ×1
AeBAD normal：权重 ×0.5（数量已够）
```

---

### 3.3 真实 291 张的内部结构（不变）

- 试件级 hold-out：不能改
- 增强图（flip/rot）跟原试件同域：不能泄漏到 domain_3
- 这是唯一可信的最终成绩单

## 四、小缺陷占比太小 — 数据生产侧（最重要）

当前流程是整图 resize 256→640 + GAP，小缺陷信号会被背景淹没。

### 4.1 必须做的数据生产（转换脚本层，后续实现）

① 缺陷中心裁剪（ROI crop，优先级最高）

```
对每个有标注的样本：
  bbox/mask → 扩边 1.5~2.0 倍 → crop
  约束：缺陷面积占 crop ≥ 15%（不够则放大 crop 或 skip）
  同时保留：
    rgb_full.jpg   # 整图（可选）
    rgb.jpg        # 缺陷 crop（主输入）
```

| 数据源 | ROI 来源 |
|--------|----------|
| 真实 YOLO | txt 框，取最大框或 merge 多框 |
| AeBAD | ground_truth mask 外接矩形 |
| bladeSynth | 像素 mask |

② 双视图样本（为后续架构预留）

```
sample_xxx/
  rgb.jpg          # defect crop（主）
  rgb_context.jpg  # 整图缩略（辅，Phase 1 可先不用）
```

③ 复制粘贴增强（bladeSynth + AeBAD 上可做）

- 把缺陷 crop 贴到正常叶片背景
- 控制尺度：缺陷占图 5%–30% 随机
- 专门缓解「缺陷太小」

④ 类别平衡

| 策略 | 做法 |
|------|------|
| 过采样 | 真实 defect 重复 3–5× |
| 欠采样 | AeBAD normal 随机抽 30% |
| Task 采样 | MAML 采 task 时保证每 task 至少 1 个真实 defect support |

⑤ 输入尺寸

- 数据集层：crop 后短边 ≥ 384（比现在的 256 更保细节）
- YOLO backbone：yolo_imgsz=640 可保持，但 crop 本身要够大

## 五、Phase 0 预训练具体怎么训

当前缺口：项目只有 MAML 入口，没有 pretrain_backbone.py。

推荐配置：

| 项 | 建议 |
|----|------|
| 初始化 | yolo26n.pt（比随机好，比纯 ImageNet 更贴近工业） |
| 冻结 | 前 50% stage 冻结，后 50% epoch 解冻最后 2 个 block |
| 优化器 | AdamW, lr=1e-4（head），1e-5（backbone 解冻后） |
| batch | 16–32（看显存） |
| epoch | 30–50（bladeSynth 大，不必 200） |
| 损失 | CE(bladeSynth) + 0.3×CE(AeBAD binary) |
| 增强 | 水平翻转、±15° 旋转、ColorJitter(弱)、不要强 blur |
| 早停 | val acc 连续 5 epoch 不涨 |

输出：weights/aviation_yolo26_pretrained.pt → Phase 1 替换 --yolo_weights

验收标准（预训练是否成功）：

1. bladeSynth val acc > 85%
2. AeBAD 正常/异常 AUC > 0.90
3. 在真实 domain_3 上 KNN（不做 MAML）比 ImageNet 初值明显提升

## 六、Phase 1 MAML 训练与调参

加载：aviation_yolo26_pretrained.pt，--freeze_backbone True

| 参数 | 当前 | 建议（数据扩充后） | 原因 |
|------|------|-------------------|------|
| ways | 2 | 2（先稳）→ 3 | 真实仍缺 contamination |
| shots | 3 | 5 | 更多 support 利于小缺陷 |
| iters | 300 | 500–800 | 域多了需更多 iter |
| meta_lr | 0.001 | 0.0005 | 预训练后略降 |
| fast_lr | 0.01 | 0.005 | 内环别破坏 backbone 特征 |
| train_domains | 0,1,2 | 0,1,2,4,5,6,7 | 加入 AeBAD |
| eval | domain 3 | 不变 | 真实金标准 |

课程（沿用现有三阶段）：

- iter 0–200：纯 CE，w_rl=0
- iter 200–500：w_rl 线性到 0.3
- iter 500+：w_rl=0.5，adapt_steps 减 1

Phase 2：--freeze_backbone False，meta_lr=1e-5，只跑 100 iter，防 catastrophic forgetting。

Phase 1 推荐命令（数据就绪后）：

```powershell
conda activate MAML
cd D:\元强化学习\代码\航空缺陷检测
python train.py --iters 500 --rgb_only True --data_dir_path D:\元强化学习\代码\data --freeze_backbone True --yolo_weights ./weights/aviation_yolo26_pretrained.pt --train_domains 0,1,2,4,5,6,7 --test_domain 3 --ways 2 --shots 5
```

## 七、架构要不要改

Phase 0–1：可以不改架构，先把 ROI crop + 预训练权重做好，通常就能有明显提升。

若 ROI crop + 预训练后 domain_3 仍 < 60%，再考虑：

| 改动 | 优先级 | 说明 |
|------|--------|------|
| 缺陷 crop 输入 | ★★★★★ | 数据层，零架构改动 |
| FPN 多尺度池化替代单层 GAP | ★★★★ | 改 backbones.py 的 pool 逻辑 |
| 双分支（crop + 整图）融合 | ★★★ | 改 multimodal_model.py |
| 注意力池化（按 activation 加权） | ★★★ | 小改 backbone |
| 检测头 + 分类头两阶段 | ★★ | 工作量大，最后考虑 |

暂不建议：换 ResNet、换更大 YOLO、上多模态 — 先把 RGB 小样本跑通。

当前架构瓶颈（common/backbones.py）：

- 整图 resize 到 640 + AdaptiveAvgPool2d
- 对占图 <5% 的 scratch 极不友好
- crop 是第一优先级，比换 backbone 更有效

## 九、预期效果与风险

| 阶段 | 合理预期 | 主要风险 |
|------|----------|----------|
| ImageNet YOLO26 + 整图 MAML | domain_3 ~50%（已有基线） | 小缺陷丢失 |
| + ROI crop | +10~20% | crop 偏了漏缺陷 |
| + bladeSynth 预训练 | +5~15% | 合成纹理偏假 |
| + AeBAD 作 meta-train 域 | +5~10% | 和真实仍有 gap |
| + 解冻 backbone | +3~8% | 过拟合 AeBAD |

最大风险：把 bladeSynth 混进 MAML → 测试虚高、真实 domain_3 反而下降。
最大机会：AeBAD + ROI crop + 预训练，三者叠加。
