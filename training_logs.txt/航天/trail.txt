四、工业 ProtoNet 四方向改进 · 现状盘点 (2026-07-07)
------------------------------------------------------------------------------

工业缺陷特点: 类内形态差异大、缺陷尺寸小、背景干扰强、跨产线域偏移明显。
原始 ProtoNet「全局均值原型 + 欧氏距离」在工程上已有精度瓶颈; 主流改进分 4 方向。
**当前总定位: Vanilla ProtoNet baseline + 工程底座, 四方向改进几乎都未做。**

  工业 ProtoNet 改进路线 · 成熟度
  ├── ① 原型计算优化     ░░░░░░░░░░  ~0%
  ├── ② 特征增强         ██░░░░░░░░  ~20%
  ├── ③ 跨域泛化         ███░░░░░░░  ~30%
  └── ④ 定位/分割扩展     ░░░░░░░░░░  ~0%

------------------------------------------------------------------------------
4.1 方向一 · 原型计算优化 — **未做（标准 ProtoNet）**
------------------------------------------------------------------------------

  核心痛点: 形态多变时简单均值被离群样本带偏, 原型无法代表真实缺陷分布。
  改进思路: 自适应加权原型 / Mean Shift / 原型重校准 / 多原型拆分 / 中心损失。

  | 改进项              | 代表工作        | 我们现状 |
  |---------------------|-----------------|----------|
  | 全局均值原型        | 原始 ProtoNet   | ✅ support_emb[mask].mean() |
  | 欧氏/余弦距离       | ProtoNet 2017   | ✅ euclidean (exp08); cosine 可选 |
  | Mean Shift 原型     | MSPro-Net 2025  | ❌ |
  | 查询集原型重校准    | DAPRN           | ❌ |
  | 多原型 / 中心损失   | —               | ❌ |

  判定: 方向 1 停留在 2017 原始 ProtoNet; MSPro-Net / DAPRN 均未接入。
  exp09 规划 support-query 关系建模 → 偏方向 1+2 交界, **尚未实现**。

------------------------------------------------------------------------------
4.2 方向二 · 特征增强 — **部分有（数据层）, 网络层几乎无**
------------------------------------------------------------------------------

  核心痛点: 微小/弱对比缺陷易被背景淹没, 全局原型匹配敏感度不足。
  改进思路: 多尺度融合 / SE·CBAM 注意力 / 局部区域上下文 / CLIP 预训练。

  | 能力                | 代表工作           | 我们现状 |
  |---------------------|--------------------|----------|
  | 工业预训练 backbone | —                  | ✅ Phase0 YOLO26+BladeSynth+AeBAD |
  | ROI 聚焦            | —                  | ✅ 转换阶段 YOLO box/mask crop (离线) |
  | 全局池化 embedding  | —                  | ✅ YOLO→AdaptiveAvgPool→128d |
  | SE/CBAM 注意力      | 注意力增强 ProtoNet| ✅ exp10 CBAM (YOLO neck→pool 前) |
  | 多尺度原型融合      | MPFnet             | ❌ 单尺度全局特征 |
  | CLIP/对比学习骨干   | MVREC 2024         | ❌ |
  | 多模态动态融合      | AsymmetricFusion   | ⚠️ 有代码, ProtoNet embed() 未走 fusion |

  ProtoNet 实际路径: embed() = concat(RGB, thermal, US) 各 128d → 384d (rgb_only 时 128d)
  判定: 预训练 + ROI 裁剪 + **exp10 CBAM** (2026-07-08 已实现, 待训评); MPFnet 等仍未做。
  **P0**: exp10 训练+终评 vs exp08 85.2% (Scheme A: 复用 Phase0 YOLO, CBAM 随机初始化)。

------------------------------------------------------------------------------
4.3 方向三 · 跨域泛化 — **有评测协议, 无适配算法**
------------------------------------------------------------------------------

  核心痛点: 元训练与实际工厂在光照/材质/设备上差异大, 直接迁移精度暴跌。
  改进思路: 域对抗 / 特征适配器 / 转导式原型校准 (DAPRN 等)。

  | 能力                | 我们现状 | 说明 |
  |---------------------|----------|------|
  | 跨试件 holdout 评测 | ✅       | domain_0–2 训 / domain_3 考, exp08 85.2% |
  | 域对抗 DANN         | ❌       | |
  | DAPRN 原型重校准    | ❌       | |
  | 转导式 query 校准   | ❌       | |
  | Feature Adapter     | ❌       | |
  | 跨域 episode 采样   | ⚠️ 证伪  | exp07 best 61.9% (作废) |
  | AeBAD 扩 meta-train | ⚠️ 证伪  | exp05 0.681 vs exp04 0.682 (作废) |
  | TaskEncoder+KB prior| ⚠️ 未接入| 有模块, ProtoNet embed() 不用 domain meta |

  判定: 「跨试件 episodic 评测 ✅ + 域适配算法 ❌」。
  85.2% 说明 baseline 在当前 2-way ROI 设定可用, 但 DAPRN 类跨产线方案 **未做**。

  ------------------------------------------------------------------------------
  4.9 v5 改动逐项拆解 + 成熟体系锚定 (2026-07-19)
  ------------------------------------------------------------------------------

  v5 相对旧版 (exp08 用的 aviation_yolo26_pretrained.pt) 共 5 个核心改动。
  所有 5 项**都是成熟体系的标准做法**，没有自创 trick；我们做的"创新"是组合 + 工程化适配。

  改动 1 · Backbone 解冻: frozen → indices[freeze=[0..5]]
  ────────────────────────────────────────────────
    代码锚点: pretrain_backbone.py:43-46, pretrain_train.py:264-268
              pretrain_model.py:77-108 (configure_backbone)
    旧版: backbone_train_mode='frozen' (unfreeze_epoch=99, 实际永不触发)
    v5:   backbone_train_mode='indices', freeze_indices="0,1,2,3,4,5"
          → 解冻 YOLO26 顶层 block 6..22 + Detect, 只冻 stem+早期 6 块
    来自: SimCLR v2 / MoCo v2 的 partial fine-tune 套路
          [1] Chen et al., "Big Self-Supervised Models are Strong Semi-Supervised Learners"
              (SimCLR v2), NeurIPS 2020 (Figure 2 显示解冻顶层 4 个 block 最优)
    为什么有效: 顶层 block 学 task-specific; 浅层学通用边缘/纹理 (跨域通用)。
              全冻 → 特征不变, 只能训 head; 全解 → 小数据集会过拟合。
              "解冻顶层 6+ 块"是工业小样本的 sweet spot。

  改动 2 · 加 SupCon 损失: CE only → CE + SupCon (w=0.5/0.5)
  ────────────────────────────────────────────────
    代码锚点: pretrain_backbone.py:78-81, pretrain_model.py:57-63 + 143-173
              pretrain_train.py:286-315
    旧版: loss_mode='ce', 单一交叉熵
    v5:   loss_mode='supcon_ce', supcon_weight=ce_weight=0.5
    来自: Supervised Contrastive Learning
          [2] Khosla et al., NeurIPS 2020 (SupCon loss, 引文 1w+)
          核心 idea: 同标签 anchor 多正样本, 不像 SimCLR 只有自身 1 个正样本;
                     对工业小样本尤其友好 (类内方差大时更稳)。
    配套: pretrain_train.py:286-288 的 combined mix_strategy 是 v5 必须的
         (alternate 一次只走 1 个 task, supcon batch 太小无法对比)。

  改动 3 · Mix strategy: alternate → combined
  ────────────────────────────────────────────────
    代码锚点: pretrain_train.py:54-55 + 291-315
    旧版: alternate — 一个 step 走一个 task, task 间轮流
    v5:   combined — 每个 step 聚合所有 task 的 feature 再算 SupCon
    来自: SupCon 原论文的 batch-level contrastive 实践
          [2] Khosla et al., NeurIPS 2020 (Algorithm 1, 单 batch 多 label)
    关键: label_namespace='global' 让不同 task 的类标号 offset 后拼到一个 batch,
         → "blade.scratch" 和 "aebad.normal" 不冲突, 但同语义靠标签聚类。
         pretrain_model.py:131-141 自动算 offset, 代码已就绪。

  改动 4 · proj_dim: 256 → 64
  ────────────────────────────────────────────────
    代码锚点: pretrain_backbone.py:82-83, pretrain_model.py:58-62
    旧版: 默认 256d 投影头
    v5:   64d 紧凑投影头 (Linear→ReLU→Linear)
    来自: SimCLR v2 / SimSiam 的投影头 ablation
          [1] Chen et al., NeurIPS 2020 (SimCLR v2) — 小投影头 + 多层 MLP
              在 metric learning 下界比大投影头更紧。
          [3] Chen & He, "Exploring Simple Siamese Representation Learning" (SimSiam),
              ICCV 2021 — 验证 64~256d 投影头去掉后效果接近 → 投影头不必太大。
    为什么: 大投影头保留太多"分类用"信息; 小投影头逼迫 backbone 学 metric-friendly 特征。
         ProtoNet 距离度量对 metric-friendly 嵌入敏感 → 涨点传导到 Meta 阶段。

  改动 5 · 温度 T: 默认 → 0.07
  ────────────────────────────────────────────────
    代码锚点: pretrain_backbone.py:84
    v5:   supcon_temperature=0.07 (SimCLR/SupCon 默认)
    来自: [2] Khosla et al., NeurIPS 2020 + [4] Chen et al., ICML 2020 (SimCLR)
    可选: temperature_adapt=True (pretrain_model.py:151-170) 是 Wen et al. 2022
         的特征范数自适应方案, v5 没开 (intra-class variance 小, 0.07 已够)。

  配套超参变化 (v5 启用):
  ────────────────────────────────────────────────
    epochs: 16 → 25 (freeze 16 → indices 全程解冻, 需要更多 iter 收敛)
    batch_size: 16 → 8 (combined mix 每 step 走多 task, 显存压力)
    数据增强: 增加 ColorJitter (hue/saturation, 工业域偏移鲁棒)
